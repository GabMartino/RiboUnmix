How the stability experiments are made

Two complementary tests of the learned shared profile Lbio: adding progressively lower-ranked datasets, and fitting separate collections of datasets. This report explains the exact dataset selection, five reference-weight policies, training procedure and paired evaluation used in the current seed-42 runs.

Based on the saved manifests and configurations in results/cumulative_stability_seed42 and results/four_panel_stability_seed42, checked against the setup, model and analysis code. Earlier Exp8 and two-policy panel reports describe historical designs.

The exact weight construction

For a selected collection D = {d1, …, dN}, order datasets by increasing global rank r. Convert rank to the positive quality value q, choose the policy below, and normalize over this selected collection.

qd = (R − rd + 1) / R = (116 − rd) / 115
πd = ad / ∑e ∈ D ae π sums to one within the active prefix or panel. Every reference dataset has a strictly positive weight.
Saved arm nameRaw adⱼWho receives the most weight?Role
equal1All datasets equally: π = 1/N.Uniform-reference baseline.
ranked_p1qdⱼThe best global ranks in the selected collection.Primary linear quality mapping.
reverse_p1qdₙ₊₁₋ⱼThe worst ranks in that same collection.Direction control for p = 1.
ranked_p3qdⱼ3The best ranks, with a stronger preference.Planned stronger-reference sensitivity check.
reverse_p3qdₙ₊₁₋ⱼ3The worst ranks, with the same concentration as ranked p = 3.Direction control for p = 3.

Reverse is an exact permutation of the weights within the selected collection. Dataset membership and row order stay fixed. The implementation reverses the ordered vector qp; it does not use 1/q, negative powers, or the bottom-N datasets. For sparse panel ranks, a newly computed “local reverse rank” would generally give different weights.

The YAML field quality_rank_power remains 1 because these configurations use weighting: explicit: the setup has already applied the chosen power when writing explicit_weights. The arm name, task metadata and explicit values identify p = 3.

Nref = 1 / ∑d πd2  ;  effective fraction = Nref / N
Reference quality composition = ∑d πd rd N_ref/N near 1 means nearly uniform weights; smaller values mean greater concentration. Lower weighted mean global rank means a reference tilted toward better QC ranks. N_ref measures weight concentration, not the number of independent biological observations.

Ranked and reversed weights have exactly the same Nref at a fixed collection and exponent. Their difference tests the assignment of weight to quality rank. Equal versus ranked changes both concentration and assignment; related datasets can still accumulate substantial source-family mass.

6. Where the ranking enters the model

For dataset d, transcript t and codon i, the configured observation mean is a target-derived scale Sdt times the sequence-derived shared profile and a dataset-specific correction:

μdti = Sdt · Lbio,ti · γdtimass_conservation: false: the final product γ · L_bio is not rescaled to force its arithmetic mean to one. L_bio itself is exported as a full-CDS mean-one profile.

Reference weights π define gamma centering

Let udti be the raw log-gamma score. For the same sequence, the model evaluates every dataset in its fixed reference D, including reference dataset identities with no observed row for that transcript. It forms a weighted center over datasets. The configured geometric_mean_one scale convention also removes each dataset's constant log offset over codons.

adt = meani in CDS udti
cti = ∑d ∈ D πd udti  ;  āt = ∑d ∈ D πd adt
log γdti = udti − cti − (adt − āt)
∑d ∈ D πd log γdti = 0  ;  meani in CDS log γdti = 0 These identities describe deterministic evaluation with a consistent set of raw scores. Training uses independent dropout draws for requested and reference evaluations. The center remains in the gradient computation.

The reference contains all N selected datasets or all datasets in the selected panel. Reference evaluation is chunked in groups of 32 dataset identities for memory; it does not replace the reference with whichever observations happen to fit in a batch. Changing π changes the center and the gradients during a fresh training run, hence can change the learned shared profile.

Local reliability wdt controls the observation loss

For each observed dataset–transcript pair, use its read density ρdt and coverage Cdt. Fit τd as the median read density over that dataset's training transcripts. Then compute:

vdt = 0.7 · √ρdt / (√ρdt + √τd) + 0.3 · Cdt
wdt = vdt / mediantraining t in d vdt The two fitted reference medians use training IDs only and are reused on validation data. These local weights are unchanged between policies within a collection.

Thus a lower-ranked dataset can still exert considerable influence on the fitted observation loss. Its smaller π changes the reference constraint; it does not directly multiply its loss by a smaller QC weight. Evaluating stability under π answers a question about the model's decomposition, not simply about discarding noisy observations.

Sources: fixed-reference gamma centering and mean construction · local reliability equation · training-only reference fitting · full training and representation walkthrough.

7. What one training batch contains

A row represents one transcript in one dataset. Rows for the same transcript share its sequence representation, while dataset identity, measured profile, replicates and local reliability can differ. Raw replicates are stored within that row; they are not counted as separate datasets.

  1. Form complete transcript groups. Include the eligible observed rows (t, d) for each transcript, requiring at least two distinct selected datasets. Missing observations are not fabricated as measured training targets.
  2. Pack groups with a quota of 32 rows per represented dataset. A transcript group stays intact. With N = 2, a full logical batch has 64 pair rows for 32 transcripts; at N = 114, the nominal ceiling is 3,648 pair rows. Sparse support changes the actual number of unique transcripts.
  3. Process smaller execution chunks when needed. Configured limits are 512 pair rows or 256,000 padded codon tokens per forward, with whole groups preserved. The optimizer targets approximately 32 unique transcripts per update using the sampler's measured packing and, if necessary, accumulation.
  4. Evaluate the shared and dataset-specific branches. All observed rows in a group contribute to the loss; fixed-reference gamma additionally evaluates the complete selected dataset reference on that sequence.
  5. Reduce losses within transcript, then across transcripts. Normalize wdt across that transcript's observed datasets and give each transcript an equal outer contribution within the logical batch.
ℓdt = meanreplicates NB2_NLL + 0.5 · (1 − PCCraw consensus)
       + 0.5 · (1 − PCCNB variance-stabilized consensus)
Lossbatch = meantranscripts t [ ∑observed d wdt ℓdt / ∑observed d wdt ] NB2 denotes the negative-binomial observation loss. Each raw replicate uses its own target-derived mean scale and the same learned γ · L_bio shape; the two PCC terms use the arithmetic replicate consensus. Gamma regularization has coefficient 0.

The negative-binomial positional loss is averaged over valid codons and multiplied by clip((CDS_length / 1000)^0.25, 0.5, 2), from the saved length-tempering parameter 0.75. Invalid or flat-target correlations follow the implementation's validity masks. Execution chunks contribute in proportion to their transcript counts. If accumulation spans unequal-sized logical batches, those batch means receive equal accumulation weight, so the 32-transcript optimizer target is approximate.

8. Exactly what the analysis measures

Predict one common sequence-derived profile per test transcript

Load each selected checkpoint and export Lbio for the saved common test IDs in sequence-only mode. The analysis validates completed exports, configuration identity, the expected transcript IDs and consistent CDS coordinates. It compares the exported full-CDS mean-one profile, without smoothing, trimming to an interior region or removing zero-count positions.

For transcript t and two fitted models A and B, let x and y be these aligned profiles over T valid codons:

PCCt = corri(xi, yi)
RMSEt = √[ (1/T) ∑i (xi − yi)2 ] PCC measures profile-shape alignment; RMSE remains sensitive to the size of deviations in the normalized profile. Report both because their conclusions can disagree.

In the panel analysis, a peak set contains positions strictly above that profile's 90th percentile. Jaccard is intersection size divided by union size; ties at the threshold are excluded. Flat profiles or empty peak sets have undefined overlap. Variance ≤ 10−12 is flagged as near-constant.

Compare policy effects on the same transcripts and endpoints

ΔPCC = meant(PCCranked,t − PCCbaseline,t)
ΔRMSE = meant(RMSEbaseline,t − RMSEranked,t) Positive values favor ranked in both definitions. Baseline is equal or the reverse policy at the same exponent. For gamma ablation, replace ranked with full and baseline with shared-only.

Plots show mean transcript metrics. CSVs also retain descriptive medians, paired effects and the fraction of transcripts with a positive effect. For each metric and comparison type, use one common finite transcript cohort across all available endpoint pairs and arms. PCC and RMSE can have different valid cohorts; exclusions and exact membership are exported.

Only validated completed predictions enter profile comparisons. Logs or checkpoints from unfinished tasks enter availability and training-progress diagnostics. The cumulative analysis never bridges a missing planned size. Panel policy comparisons require the same pair on both sides; three full-model pairs must be compared with those same three shared-only pairs, even if all six shared-only pairs are available.

These test exports cannot measure count reconstruction. Sequence-only predictions use dummy observation targets. Validation fit is reported at the checkpoint selected by validation loss, making it a selection-dependent diagnostic. Independent test-count accuracy would require a separate prediction pass on genuine held-out observations.

9. What would strengthen the narrative—and what would not

Evidence consistent with quality stabilization

Ranked weights improve matched adjacent PCC and RMSE, reduce cumulative drift, and outperform reversed weights at the same exponent. The profiles retain structure, and panel agreement provides a complementary check across different sources.

Evidence requiring a narrower claim

Ranked and reverse improve similarly; PCC improves while RMSE worsens; only the strongest exponent helps; or the effect depends on a particular transition or panel pair. Report these patterns directly rather than claiming a general benefit.

Why a monotonically falling equal-weight curve is not required

Lower QC rank does not guarantee that a dataset adds only noise. Additional observations can improve estimation and expand transcript support. The selected sets overlap, the proportion newly added varies, and the shared sequence model can regularize both weighting arms. Adjacent agreement can therefore remain high—or rise—under equal weighting. The question is whether ranked weighting improves the matched comparison, not whether equal must deteriorate at every step.

Limits of the present experiment

  • Stability is not biological accuracy. Two models may share a systematic error; overly flat profiles can look close in RMSE. Use profile variance, peak agreement and independent biological evidence together.
  • One training seed gives conditional evidence. The six panel pairs share four fitted models, and the cumulative steps share endpoints. They are not independent training replications; these reports provide no across-seed confidence intervals or significance tests.
  • Changing N changes several things. Dataset quality, count, transcript eligibility, validation membership, reliability fits and training duration can all vary. Within-N policy effects are matched, but the across-N trajectory is not a pure manipulation of observation quality.
  • The reference itself changes with the collection. π is renormalized over a new set at each N. A drifting Lbio can reflect a changing definition of the reference as well as estimation error.
  • QC is a proxy. The table ranks observable properties, not ground-truth shared signal. Correlated QC components can give related properties extra influence. The frozen table does not establish that all QC components were computed on training transcripts only; that verified restriction applies to local reliability fitting.
  • Dataset concentration is not source independence. Reverse preserves the multiset of dataset weights but can change total weight by source family. Cumulative prefixes can include only part of a source family, whereas the four-panel design keeps families together.
  • Partial snapshots have incomplete contrasts. New exports can change the common finite cohort. Preserve the HTML and CSV snapshot when citing results; compare like-for-like endpoints before pooling anything.

A sharper follow-up: freeze common training/validation IDs and reliability references across N, retain the fresh matched policy fits, and add a fixed high-quality reference as a separate control. That would help separate changes in reference definition from adding observations. Known-signal synthetic corruption or an external biological endpoint would then test accuracy as well as stability. These controls are suggestions, not parts of the current runs.

10. Run, refresh and trace the experiment

The simple launchers construct their own setup from the dataset YAML, ranking TSV, configured parquet files and sequence encodings. They do not require a previous experiment's result manifest. The first array worker creates shared inputs; the remaining workers reuse the saved setup. Prepare on the training machine because saved training configurations contain that machine's absolute paths.
