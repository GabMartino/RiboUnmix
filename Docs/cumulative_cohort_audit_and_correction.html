RiboUnmix · Cohort correction · Audited 2026-09-16 · Seed 42

Keep transcripts fixed when adding datasets

The legacy cumulative experiment changed training and validation membership as N increased. The existing models have now been re-evaluated on identical real test observations, and a separate experiment setup fixes all three transcript folds across every dataset count.

The original setup did not fully control the intended experiment. A common sequence-only test set supports Lbio comparisons, but does not make observed validation cohorts or training cohorts identical. This should have been checked before interpreting across-N observed-profile curves.

1. What was coherent, and what changed?

The earlier splitter first held out 1,771 common test sequences. At each N it then found transcripts supported by at least two selected datasets and sampled a new validation fold, leaving the remainder for training. This increased usable training coverage as datasets entered, but it also changed which transcripts were used for fitting and checkpoint selection.

  2. Intersect with usable positive observations in all 114 configured datasets, including datasets whose runs are unfinished. The cohort stays fixed when later results arrive.
  3. Load each original best-validation-loss checkpoint and its saved configuration. Use real replicate profiles; the observed target is their arithmetic mean. The original sequence-only export's dummy targets are not used.
  4. For each dataset, calculate PCC(μ, observed) and PCC(Lbio, observed) on exactly the same 704 transcripts and CDS masks. Average transcripts equally. Dataset ranking never weights the evaluation metric.
  5. Show individual dataset curves. Aggregate views additionally distinguish all N dataset identities from the fixed best-two identities, Patel and Calviello.

At N=40, fixed-cohort μ PCC under equal weighting ranges from 0.307 for Riepe to 0.665 for Sharma. This spread remains after matching transcript identities; it is not explained solely by different transcript cohorts.

The production PCC convention assigns zero to near-constant profiles. The cohort selects broadly observed transcripts, so its absolute PCC values should not be compared directly with the earlier unmatched validation means as evidence of improved modeling.

This repairs the evaluation comparison. The weights in an existing checkpoint still reflect its original training cohort. A corrected evaluation cannot retroactively remove that training-design confound.

The model architecture, replica loss, optimizer settings and five reference policies follow the existing experiment. There are 35 fresh trainings with one seed. Each N starts a new model; no previous checkpoint supplies initialization.

Local reliability parameters are fitted using the 5,714 training transcripts only. The setup audit checked all 271 dataset/prefix reference entries: each reused dataset has identical fitted reliability parameters across N, and zero held-out rows are used for fitting them.

The reference policies remain equal, ranked_p1, reverse_p1, ranked_p3 and reverse_p3, with q=(116−rank)/115 and π proportional to qp. Reverse permutes the same weights within the selected prefix. π centers gamma; local reliability weights separately weight the observation loss.

Scope: this complete-case experiment studies transcripts observed across the full collection. It uses fewer training transcripts than the legacy coverage-oriented setup. The new 714-transcript test fold belongs to these fresh runs; it is distinct from the 704-transcript cohort used to re-evaluate old checkpoints.

For broader coverage later, a separate experiment can assign global transcript roles once and allow additional training transcripts as observations become available. That answers a broader data-expansion question. The complete-case design above directly controls transcript membership for the current dataset-addition question.

Implementation: complete-cohort construction · training entry point · prepared split · prepared design and reference weights.

4. What this means for the model narrative

  • μ fit and Lbio agreement answer different questions. Dataset-specific correction can retain observed-profile fit while the shared profile changes. A larger PCC(μ,y)−PCC(Lbio,y) gap identifies a larger fitted shape contribution; it does not establish that gamma recovered exclusively technical bias.
  • Matched evaluation still shows modest policy differences. At N=40 on the best-two observations, Lbio PCC is 0.369 for equal, 0.375 for ranked_p1 and 0.372 for reverse_p1; μ PCC is 0.532, 0.536 and 0.545 respectively. These partial results do not show an overwhelming or uniform ranking advantage.
  • The corrected training tests the intended controlled question. Compare paired adjacent-N Lbio stability, accumulated drift from N=2, profile variance and observed fit on fixed targets. Equal-weight stability is not required to fall monotonically as N grows: incoming data can also improve estimation.
  • Direction and concentration need separate contrasts. Ranked versus reverse at the same exponent holds dataset-weight concentration constant. Ranked versus equal changes both concentration and assignment to quality ranks.
  • One seed supports conditional evidence. Many transcripts improve precision for this fitted collection of models; they are not independent training repetitions. Biological correctness requires independent evidence, and the transcript scope used to compute the global QC ranking still needs verification.

The defensible target claim is that a quality-based reference preserves an informative shared profile under controlled dataset additions while retaining useful dataset-level observation fit. The corrected experiment makes that claim testable; its result remains empirical.

The two existing analysis scripts remain useful

Cumulative analysis compares Lbio on common held-out sequences and now displays the cached fixed-observation test figure directly, with the original validation curves in an expandable diagnostic section. Its default still reads the legacy runs; pass the corrected experiment root to analyze fresh runs.

Four-panel analysis compares Lbio on common held-out sequences across all six panel pairs. It now explicitly audits common validation/test roles and reports panel-specific training coverage. Its logged validation scores average different observation collections across panels; the cumulative test re-evaluation does not evaluate the panel checkpoints.

Both scripts run on CPU, read saved artifacts and export fold audits. Neither changes training membership or runs new checkpoint inference. Common held-out sequences make their Lbio metrics comparable; identical training transcripts are an additional experimental control.
