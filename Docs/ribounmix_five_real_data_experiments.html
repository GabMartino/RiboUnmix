RiboUnmix: five real-data experiments for validating the shared signal

A detailed experimental plan for testing whether the shared profile \(L_t\) learned from 114 heterogeneous Ribo-seq datasets is reproducible, depleted of dataset-specific observation effects, and enriched for independently expected translation biology.

Central validation goal. The real-data experiments should not claim that \(L_t\) is the true biological profile by construction. Instead, they should test whether \(L_t\) behaves as a more biologically reliable shared representation than the raw experimental profiles: reproducible across independent dataset collections, depleted of dataset-specific technical signatures, and enriched for conserved translation-related structure. \[ \boxed{L_t\text{ is useful if it is reproducible, technically decontaminated, and biologically informative.}} \]
Selected experiments
  1. Independent-panel convergence of \(L_t\)
  2. Unsupervised dataset-specific \(\gamma\) fingerprints
  3. Association of \(\gamma\) with data-derived QC characteristics
  4. Biological motif metaprofiles in \(L_t\)
  5. Stability of \(L_t\) as the number and diversity of datasets increase

Conceptual framework

For transcript \(t\), dataset \(d\), codon position \(i\), and replicate \(r\), the model describes the expected measured profile through

\[ Y_{dtri}\sim \operatorname{NB2}(\mu_{dti},\alpha_{dti}),\qquad \mu_{dti}=S_{dt}L_{ti}\gamma_{dti}. \]

Here \(L_{ti}\) is the dataset-independent sequence-dependent component, whereas \(\gamma_{dti}\) is the dataset-specific multiplicative observation component. With \(g_{dti}=\log\gamma_{dti}\),

\[ \log\frac{\mu_{dti}}{S_{dt}}=\log L_{ti}+g_{dti}. \]

The fixed-reference constraints define a stable decomposition but do not prove biological truth. The real-data section must therefore test several independent predictions that should hold if this decomposition is scientifically meaningful.

Interpretation caveat. Since the 114 datasets may differ in both protocol and biological condition, \(\gamma_d\) should initially be called a dataset-specific observation effect, not automatically a technical bias. Genuine condition-specific biology can also be dataset specific. Technical interpretation is strongest where learned signatures align with known protocol variables or recognizable library-processing effects.

Experiment 1 — Independent-panel convergence of the shared representation

Primary validationMetadata-lightCross-model reproducibility

Scientific question

If \(L_t\) captures a stable shared sequence-dependent translation representation rather than peculiarities of a particular collection of datasets, do completely independent groups of Ribo-seq experiments lead to the same inferred \(L_t\)?

Design

Partition the 114 datasets into four disjoint panels

\[ \mathcal D^{(1)},\mathcal D^{(2)},\mathcal D^{(3)},\mathcal D^{(4)},\qquad \mathcal D^{(a)}\cap\mathcal D^{(b)}=\varnothing\quad(a\neq b), \]

with approximate sizes \(29,29,28,28\). Balance the panels using observable properties such as log read depth, positional coverage, number of eligible transcripts, and replica agreement where available. Train four independent models, yielding

\[ L_t^{(1)},\quad L_t^{(2)},\quad L_t^{(3)},\quad L_t^{(4)}. \]

All four models must use the same held-out transcript IDs. For the primary comparison, use uniform fixed-reference weights within each panel:

\[ \pi_d=\frac{1}{|\mathcal D^{(k)}|},\qquad d\in\mathcal D^{(k)}. \]

The transcript-dataset reliability weights \(w_{dt}\) remain part of the training loss and are conceptually distinct from \(\pi_d\).

What “disjoint” means operationally. The split is stricter than unique dataset names. Datasets inferred to come from the same publication/source family (the author_year prefix, unless an explicit source_identifier is available) are an indivisible assignment unit. Thus all conditions and replicates from one source occur in exactly one panel: \[ s(d)=s(d')\;\Longrightarrow\;p(d)=p(d'). \] The launcher asserts both dataset-level disjointness and source-family-level disjointness before training. With the current 114 datasets this keeps 85 source families intact while still producing exact panel sizes \(29,29,28,28\).

For the leakage-free experiment, each dataset's reliability references (depth scale \(\tau_d\) and raw-score normalization median) are fitted using only that panel's training transcript IDs, then frozen when weighting validation and test rows. Held-out rows therefore cannot influence \(w_{dt}\).

Primary metric

For every held-out transcript and panel pair \((a,b)\), compute

\[ \rho_t^{(a,b)}=\operatorname{PCC}\!\left(L_t^{(a)},L_t^{(b)}\right). \]

Also report Spearman correlation and mean-one RMSE. There are six panel-pair comparisons.

Essential controls

  • Shared-only model: \(\gamma=1\).
  • Direct sequence-to-profile baseline: matched backbone without the decomposition.
  • Common test set: all comparisons use exactly the same transcripts.
  • Balanced panels: avoid confounding panel identity with overall experimental quality.

Central hypothesis

\[ \boxed{ \operatorname{PCC}(L_{\mathrm{full}}^{(a)},L_{\mathrm{full}}^{(b)}) > \operatorname{PCC}(L_{\gamma=1}^{(a)},L_{\gamma=1}^{(b)}) } \]
Interpretation of a positive result. Distinct experimental collections converge toward the same sequence-dependent latent profile once dataset-specific structure can be allocated to \(\gamma\). This is one of the strongest metadata-free arguments that \(L\) is not tied to a particular experimental panel.

Recommended outputs

  1. Panel-quality balance plots.
  2. Violin/box plots of all six per-transcript agreement distributions.
  3. Full model versus \(\gamma=1\) versus direct baseline.
  4. Representative held-out transcripts with the four inferred \(L_t\) curves overlaid.

Failure modes

  • Low convergence restricted to sparse transcripts suggests a measurement-reliability limit.
  • Low convergence globally suggests excessive dependence on reference-panel composition.
  • No improvement over \(\gamma=1\) suggests that the observation branch is not materially improving shared-signal recovery.

Experiment 2 — Unsupervised dataset-specific \(\gamma\) fingerprints

InterpretabilityMetadata-free discoveryObservation signatures

Scientific question

Does the dataset-specific branch discover reproducible and interpretable sequence-dependent observation signatures even when protocol metadata are not provided to the model?

Core idea

For each dataset \(d\), summarize \(g_{dti}=\log\gamma_{dti}\) according to predefined sequence features around the modeled footprint/ribosome position. This converts millions of positional corrections into a compact dataset-level fingerprint.

Feature families

  • nucleotide identity near inferred 5' footprint ends;
  • nucleotide identity near inferred 3' footprint ends;
  • terminal dinucleotides;
  • local GC and AU fractions;
  • codon identity around A-, P-, and E-site positions;
  • amino-acid identity and local sequence composition windows.

Dataset-level effect scores

For binary feature \(F_k\), one useful statistic is

\[ B_{dk}=\mathbb E[g_{dti}\mid F_k=1]-\mathbb E[g_{dti}\mid F_k=0]. \]

For a categorical nucleotide feature,

\[ B_{d,p,n}=\mathbb E[g_{dti}\mid \text{nucleotide }n\text{ occurs at offset }p]. \]

Flatten these summaries into \(\mathbf B_d\), and stack all datasets into

\[ \mathbf B\in\mathbb R^{114\times K}. \]

Analysis

  • Hierarchically cluster datasets using \(\mathbf B_d\).
  • Use PCA/UMAP only as secondary visualization.
  • Plot a dataset-by-signature heatmap.
  • Overlay available metadata only after training.
  • Leave missing metadata as missing annotations rather than excluding those datasets.

Validation with partial metadata

If a subset of datasets has known nuclease, adapter, laboratory, publication, or related protocol annotations, test whether these labels are predictable from \(\gamma\)-fingerprints despite never being supplied during training.

Strong interpretation. If experiments sharing known protocol features cluster through \(\gamma\), the observation branch is recovering structured experimental signatures rather than absorbing arbitrary nuisance degrees of freedom.

Critical control

Extract analogous fingerprints from \(L\). Protocol-associated signatures should be substantially weaker in \(L\) than in \(\gamma\):

\[ \boxed{\text{protocol predictability from }\gamma > \text{protocol predictability from }L.} \]

Recommended figure

A clustered 114-row heatmap with sequence-signature columns and metadata annotation bars. A companion panel can display the strongest learned motif effects for representative datasets.

Experiment 3 — Association of learned observation effects with data-derived QC

External validationProtocol metadata not required

Scientific question

Are the learned dataset-specific effects associated with independently measurable properties of the experimental data?

Dataset-level QC features

Examples include

\[ Q_d^{\mathrm{depth}}=\operatorname{median}_t D_{dt},\qquad Q_d^{\mathrm{coverage}}=\operatorname{median}_t C_{dt}, \] \[ Q_d^{\mathrm{rep}}=\operatorname{median}_t\operatorname{PCC}(Y_{dt1},Y_{dt2}), \] \[ Q_d^{\mathrm{zero}}=\mathbb E_t\left[\frac{\#\{i:Y_{dti}=0\}}{L_t}\right]. \]

Where available, also quantify frame periodicity, start/stop metagene quality, footprint-length distribution, total reads, and transcript support.

Gamma and dispersion summaries

\[ G_d^{\mathrm{abs}}=\mathbb E_{t,i}[|g_{dti}|],\qquad G_d^{\mathrm{var}}=\operatorname{Var}_{t,i}(g_{dti}), \] \[ G_d^{\mathrm{motif}}=\|\mathbf B_d\|_2,\qquad A_d=\mathbb E_{t,i}[\log\alpha_{dti}]. \]

Tests

  • Spearman associations between QC variables and gamma/dispersion summaries.
  • Robust multi-variable regression.
  • Partial correlations, e.g. testing depth while controlling coverage.
  • Stratified analyses to detect whether associations are driven only by the lowest-quality datasets.
Separate stochastic reliability from systematic bias. Low depth may increase uncertainty or learned dispersion without producing a large systematic \(\gamma\). Conversely, a deep dataset can have a strong sequence-selective technical effect. This distinction is scientifically useful rather than a nuisance.

Recommended figure

A compact rank-correlation matrix and selected scatterplots linking dataset QC measures to gamma magnitude, motif-signature strength, and mean dispersion, with uncertainty intervals across the 114 datasets.

Experiment 5 — Biological motif metaprofiles in the shared representation

Biological validationPredefined motifsPosition-resolved

Scientific question

Does \(L_t\) retain reproducible sequence signatures independently expected from translation biology?

Correct biological target

Since \(L_t\) is normalized within a transcript, it should not be validated as an absolute translation-efficiency or protein-abundance predictor. The appropriate target is within-transcript positional translation structure.

Predefine motif families

  • polyproline and consecutive-proline motifs;
  • A-, P-, and E-site codons;
  • positively charged nascent-peptide windows;
  • specific elongation-associated amino-acid contexts;
  • termination-proximal occupancy;
  • collision-prone sequence contexts when sufficiently well supported.

Metaprofile construction

For motif \(m\) centered at position \(i\), define

\[ M_L^{(m)}(k)=\mathbb E[L_{t,i+k}\mid m\text{ occurs at }i],\qquad -k_{\max}\le k\le k_{\max}. \]

Analogously calculate \(M_Y^{(m)}(k)\) and \(M_\gamma^{(m)}(k)\).

Critical robustness test

Compute the biological metaprofiles independently from all four models trained in Experiment 1:

\[ M_{L^{(1)}}^{(m)},\quad M_{L^{(2)}}^{(m)},\quad M_{L^{(3)}}^{(m)},\quad M_{L^{(4)}}^{(m)}. \]

A motif becomes substantially more convincing if its positional signature is recovered from four disjoint experimental panels.

Biological-versus-technical partitioning

For a predefined biological motif \(m_{\mathrm{bio}}\), the desirable pattern is

\[ \text{strong, reproducible effect in }L,\qquad \text{weak or heterogeneous effect in }\gamma. \]

For a footprint-end sequence preference \(m_{\mathrm{tech}}\), the desirable pattern is approximately the reverse:

\[ \text{weak shared effect in }L,\qquad \text{strong dataset-dependent effect in }\gamma. \]
Ideal qualitative result. Raw Ribo-seq contains both conserved translation-associated structure and experiment-specific sequence preferences. RiboUnmix enriches the former in \(L\) and the latter in \(\gamma\).

Optional codon-level validation

Estimate a codon-specific shared effect, for example

\[ E_c=\mathbb E[L_{ti}\mid c\text{ occupies a chosen ribosomal site}], \]

and compare it with an independent codon-decoding proxy such as tRNA adaptation. This is a plausibility test rather than an exact mechanistic identity because ribosome occupancy depends on local context and traffic.

Recommended figure

  1. One or two predefined biological motif metaprofiles.
  2. The same metaprofiles across the four independent-panel models.
  3. A technical footprint-end signature localized predominantly in \(\gamma\).
  4. Optional codon-effect comparison with an external biological proxy.

Experiment 8 — Stability of \(L_t\) as the number and diversity of datasets increase

Scaling behaviorRandom subsetsMulti-view evidence

Scientific question

Does the inferred shared representation become more stable as the model receives more heterogeneous experimental views?

Design

Choose dataset-panel sizes such as

\[ N\in\{2,5,10,20,40,80,114\}. \]

For every \(N<114\), sample multiple independent subsets

\[ \mathcal D_N^{(1)},\ldots,\mathcal D_N^{(K)}. \]

Use the same quality-aware sampling infrastructure as Experiment 1. Multiple subsets are essential because a single subset would confound dataset count with dataset identity.

Primary stability statistic

\[ R_N=\mathbb E_{aReport the complete per-transcript distribution and uncertainty across dataset subsets.

Secondary reference statistic

\[ R_N^{(114)}=\mathbb E_{a,t}\left[\operatorname{PCC}\left(L_t^{(N,a)},L_t^{(114)}\right)\right]. \]

This is useful but secondary because the 114-dataset solution is not ground truth.

Main prediction

\[ \boxed{N\uparrow\quad\Longrightarrow\quad R_N\uparrow\quad\Longrightarrow\quad\text{eventual plateau}.} \]

Diversity versus number

After Experiment 2 defines the dataset fingerprint \(\mathbf B_d\), define

\[ \Delta(d,e)=\|\mathbf B_d-\mathbf B_e\|_2. \]

For a dataset subset \(\mathcal D\),

\[ \Delta(\mathcal D)=\frac{2}{|\mathcal D|(|\mathcal D|-1)}\sum_{dThen ask, at fixed \(N\), whether experimentally more diverse subsets yield a more stable \(L\):

\[ \Delta(\mathcal D_N)\uparrow\quad\Rightarrow\quad\text{higher cross-subset agreement of }L. \]
Why this is stronger than a simple data-size result. If only \(N\) matters, more data improve estimation. If observation diversity additionally predicts stability, the experiment supports the deeper RiboUnmix idea that distinct measurement processes provide complementary information for separating shared and dataset-specific structure.

Controls

  • multiple dataset-subset seeds;
  • fixed held-out transcript IDs where possible;
  • uniform \(\pi_d\) within each subset for the primary analysis;
  • unchanged local reliability weighting \(w_{dt}\);
  • report transcript support at every \(N\);
  • do not interpret the 114-dataset solution as ground truth.

How the five experiments reinforce one another

The experiments should be presented as one triangulation argument:

\[ \boxed{ \begin{array}{ccccc} \text{different panels}&\Rightarrow&\text{same }L&\Rightarrow&\text{reproducibility}\\[1.5mm] \gamma&\Rightarrow&\text{dataset fingerprints}&\Rightarrow&\text{observation specificity}\\[1.5mm] \gamma+\text{QC}&\Rightarrow&\text{independent associations}&\Rightarrow&\text{external validation}\\[1.5mm] L+\text{motifs}&\Rightarrow&\text{translation signatures}&\Rightarrow&\text{biological plausibility}\\[1.5mm] N\uparrow&\Rightarrow&\text{stability}\uparrow&\Rightarrow&\text{evidence accumulation} \end{array}} \]

No single experiment proves that \(L\) is biological truth. Together, they test independent consequences that should simultaneously hold if \(L\) is a more reliable shared representation of sequence-dependent translation dynamics.

Recommended real-data paper structure

  1. Dataset collection and evaluation protocol. Describe the 114 datasets, missing metadata, profile harmonization, replicas, quality summaries, and held-out transcripts.
  2. The shared representation converges across independent dataset panels. Experiment 1.
  3. Dataset-specific corrections reveal latent experimental signatures. Experiment 2.
  4. Observation effects track independent dataset-quality characteristics. Experiment 3.
  5. The shared representation preserves conserved translation signatures. Experiment 5.
  6. Shared-profile stability increases with experimental evidence and diversity. Experiment 8.

Suggested headline result

Models trained on disjoint collections of heterogeneous Ribo-seq experiments converge toward similar shared sequence-dependent profiles. Dataset-specific observation factors reveal interpretable footprint-sequence signatures and associate with independent experimental quality characteristics, while the shared representation preserves conserved translation-related positional signals. The reproducibility of this shared representation increases as additional and more diverse experimental views are incorporated.

This would validate the learned decomposition itself, rather than relying only on reconstruction accuracy.
