1. Scope and the central idea

Training learns a shared sequence-dependent profile and dataset-specific corrections to it. Raw replicate counts supervise their product through a negative-binomial loss; the mean replicate profile supplies two correlation losses. The sequence encoder sees each unique transcript once per forward. Dataset-conditioned observations retain their own rows, counts, reliability weights, and replicate axis.

sequence xt → shared load Lti
(sequence xt, dataset d) → correction γdti and dispersion αdti
hdti = γdtiLti / meani valid(γdtiLti)
replicate mean prediction μdtri = observed replicate scale Ŝdtr × hdti

This document starts from the existing Docs explanations, then checks their claims against the working-tree source and current YAML. It describes a fresh invocation of the real-data entry point without overrides. A historical run is defined by its saved resolved configuration, split/reference manifests, checkpoint, and source version. The current checkout already contains changes; this report is not a reconstruction of every past experiment.

Scientific target: relative allocation along a coding sequence (CDS), conditional on observed transcript depth. Neither a transcript ID nor a target profile enters the biological encoder. The final count prediction does use the target-derived scale. Accurate count-profile prediction therefore does not demonstrate prediction of absolute abundance.

3. Five distinct objects that must not be confused

ObjectNotationWhat is shared or different?
Transcriptt, length TtA biological sequence, with one codon at each modeled position. Same sequence across its dataset rows.
DatasetdA named artifact/condition with a global categorical ID. Names can themselves contain “rep1”; the configured artifact identity defines d.
Observed pair(t,d)One retained transcript row in one selected dataset. This is the flat dataset's __getitem__ unit.
Raw replicater = 1,…,RdtA count vector inside a pair, not another pair row and not another supporting dataset. No replicate embedding is learned.
Reference evaluation(t,k), k ∈ DrefA bias-network evaluation used to define gamma's reference. It can exist without a measured row for that transcript in dataset k. It does not create a target or a loss observation.

There are also four different dataset sets: the 131-ID vocabulary, the 114-dataset split universe, the two selected training datasets, and the gamma reference panel (by default the selected datasets). Increasing one does not automatically increase the others.

A missing dataset observation is absent. A measured zero at a valid codon is a genuine NB target. A padded zero is excluded by masks. These have different meanings even though two of them may be stored numerically as zero.

Reliability preprocessing

The current preprocessing script's default is:

density Ddt = mean counts per codon; coverage Cdt = fraction of positive codons
τd = median positive density among eligible rows
depth_scoredt = √Ddt / (√Ddt + √τd)
raw_weightdt = 0.70 × depth_scoredt + 0.30 × Cdt
wdt = raw_weightdt / medianeligible t(raw_weightdt)

Weights may exceed one. Runtime normally uses the stored positive values exactly, so the script's current default alone does not establish how an older artifact was generated. An optional reliability_reference_manifest applies references fitted on explicit training IDs; it is null in the base configuration.

Duplicate pairs are rejected. Negative/nonfinite weights and malformed profiles are rejected. Historical weight-zero rows are excluded; the weighted loader also excludes positive-weight stored profiles with no counts. Replicates must be finite, nonnegative, nonempty and aligned in length; a zero-count replicate is allowed when its pair has positive information overall. Stored consensus and replicas must agree in length, but the loader does not require equality between stored ribo and their mean: it replaces the runtime target with that mean.

5. Transcript splits precede sampler eligibility

  1. Build transcript metadata from the sequence table and the configured master dataset union.
  2. Find validation candidates with a retained positive-weight row in every master dataset. The default master universe is the entire 114-entry mapping, independent of the selected training pair.
  3. Assign each common transcript a split-only reliability score: the median of its dataset-specific weights. Combine a reliability quantile bin (10 configured bins) with a CSS-count class: 0, 1, 2–3, or 4+ conserved stalling sites.
  4. With seed 42, select round(0.1 × common_candidate_count) transcripts using joint stratification. This is 10% of the common pool, not 10% of the master union.
  5. Assign every other master-union transcript to training. The selected datasets then contribute the observations they actually contain.
  6. The training sampler further requires at least two distinct selected datasets with eligible rows for that transcript. With the default two datasets, only their shared eligible training transcripts enter updates.
Split role is not the same as exposure to optimization. A transcript can be labeled training in the manifest and still be excluded from the sampler because only one selected dataset contains it. Replicate count does not rescue that transcript.

The default has training and validation only; prediction uses validation IDs. External experiment manifests can supply panel-specific training IDs plus disjoint validation/test IDs. Validation and prediction samplers allow one observed dataset per transcript, whereas the default training sampler requires two.

CSS guides split composition and remains available for diagnostics. It is neither an input channel to the active networks nor a supervised loss term. The split helper discovers common membership from IDs and positive weights; profile-value checks occur later in the datamodule. Legacy positive-weight all-zero rows can therefore make advertised common membership differ from actual usable support.

6. What does “batch size 32” actually mean?

For an eligible transcript, form the complete group Gt = {(t,d): d has an eligible selected observation}. The sampler keeps this group atomic. It never randomly chooses just one of that transcript's available datasets.

Actual packing algorithm

  1. Construct groups in deterministic transcript-ID order; retain groups meeting the support threshold.
  2. Sort by decreasing CDS length, with deterministic group ordering for ties.
  3. Append a complete group unless it would make any dataset exceed its quota of 32 rows. If it would, close the current logical batch and start the next.
  4. Keep the final partial batch (drop_last=False).
  5. Randomize the order of complete packed batches across epochs. Current group membership within batches remains fixed; this avoids changing the number of execution chunks between epochs.
  6. Split a logical batch into smaller execution chunks only between complete transcript groups.

Logical batch

Defines the loss population. Each represented dataset has at most 32 observed rows. With D datasets, B ≤ 32D.

Execution chunk

A subset of whole groups materialized in one forward/backward. Memory limits control its size.

Optimizer window

A logical batch or A accumulated logical batches. AdamW updates once after their chunks contribute.

With complete support across D datasets, a full logical batch contains exactly 32 transcripts and 32D rows. With incomplete support, the transcript count can be greater than 32, and some dataset quotas can remain underfilled. Quota is not a command to oversample missing observations or equalize dataset counts.

Length sorting is for efficient padding, not random cropping. In the active real-data configuration, full retained CDSs enter the model; no maximum-length cutoff is configured. One unusually long transcript can exceed the nominal execution memory limit because groups are atomic.

Concrete dimensions

For t1/t2 above: U=2, B=4, lengths [9,9,7,7]. The padded biological array before packing is [2,9,97], but packed data is [16,97]. Targets and codons are [4,9]. If the four pairs carry [2,1,3,2] replicates, replica_pad is [4,3,9] and replica_mask is [4,3]. Group IDs are [0,0,1,1].

The loader checks that same-transcript rows have identical codons and any active extra features before selecting a canonical sequence. The biological forward then gathers its unique outputs back to the pair axis. Thus equal Lt across dataset rows is structural, rather than something the optimizer must learn.

Padded codon ID 0 is not an unknown-codon token; it is a valid codon ID used as a placeholder behind a mask. Packed bidirectional recurrence prevents the backward GRU from incorporating artificial padding. Genuine zero counts at valid positions stay in the loss.

9. Representations: the same sequence, two independent encoders

Biological input: 97 fixed channels

3 nucleotide positions × 4 one-hot channels = 12
64-codon one-hot = 64
21 amino-acid/stop categories = 21
Total = 97

The 64×97 lookup table reconstructs these features from codon IDs. It is fixed, not a learned embedding. Compact sequence caches use uint8 codon IDs; dense channels are built only for the unique transcripts in the current chunk.

Bias GRU input: 68 learned channels

dataset embedding = 32
codon embedding = 16
3 nucleotide positions × embedding size 4 = 12
amino-acid embedding = 8
Total = 68

Nucleotide and amino-acid IDs are derived from the same codon encoding. These features contain no additional sequence information beyond codon identity, but provide a different parameterization and inductive bias.

In fixed-reference mode, dataset embedding vectors are centered by the unweighted mean over selected experiment IDs, not over all 131 vocabulary rows and not by the quality weights. The centered 32-dimensional vector is repeated at each codon. The same model parameters process all datasets; a run does not create one whole model per dataset.

Optional sequence features

exo, gmp, tmp, openen, and fra each declare 3 channels; tAI_profile_codon declares 1. Routes are none, biological, dataset_bias, or both. Missing sentinels and nonfinite values are replaced before multiplying by the configured scale. These are observed features, with no fitted normalization implied by that scale.

All routes are off in the current real-data default. Enabling exo/gmp/tmp/openen/tAI for both branches adds 13 channels: biological input becomes 110 and current bias input becomes 81. It does not share GRU weights or connect the two branches.

10. Forward computation and gradient paths

Unique transcript sequences [U, variable T, 97]
  → biological BiGRU: 2 layers, 256 per direction
  → Linear(512,512) → GELU → Dropout(0) → Linear(512,1) → Softplus
  → normalize over valid codons → L_bio [U,Tmax]
  → gather by transcript_group_index → L_bio [B,Tmax]

Pair codons + dataset IDs [B, variable T]
  → concatenate learned embeddings [B,Tmax,68]
  → independent bias BiGRU: 2 layers, 256 per direction
  → channel LayerNorm → context [B,Tmax,512]
  → concatenate dataset embedding (32) + position features (3)
  → assembled features [B,Tmax,547]
       ├─ gamma MLP: 547 → 128 → 128 → 1, GELU + dropout 0.1
       │    → clamp raw score to [−8,8] → reference centering → exp → gamma
       └─ stop-gradient → alpha MLP: 547 → 128 → 1, GELU + dropout 0.1
            → log_sigma (the public name for log-alpha)

The three position features are i/max(T−1,1), exp(−i/100), and exp(−(T−1−i)/100), with i starting at zero. They encode relative position and distance from the CDS start/stop.

Lti = softplus(zti) / meanvalid i softplus(zti)
ρti = Lti / (1 + Lti)
λti = log(1 + Lti), Jt = meanvalid i λti

The last three quantities are derived diagnostics. There is no learned flux head, additive bias, queue simulator, or supervised “true biology” target in the active forward. “Biological” names the intended interpretation of a shared normalized latent profile.

Gamma starts at one because its final linear layer is initialized to zero. Biological load starts near, but not exactly, flat because its output weights have a small random initialization. The dispersion head starts with log_sigma=0.2, corresponding to α≈1.221 before learning.

Attached versus detached paths: NB and both PCC losses train the mean through L and gamma. NB trains the alpha head too, but alpha's input context is detached, so that path cannot train the bias GRU or its embeddings. NB-VST PCC also detaches alpha. These restrictions prevent alpha gradients from changing the shared bias representation, but they do not make the numerical values of alpha irrelevant to mean optimization.

Both branches train jointly from the first update. There is no alternating biological/bias fitting stage or pretraining schedule in this default.

Source: biological model, bias encoder and detached alpha context, alpha head.

11. The reference panel is an internal model computation

Before model creation, the entry point resolves the selected and reference IDs and their quality weights. Reference IDs default to the selected datasets; an explicit reference must be a subset of them. IDs and weights are checkpointed. They are not re-estimated from each batch or from the transcript's observed counts.

Quality-rank weighting

qd = (Rrank,max − rankd + 1) / Rrank,max
πd = qdp / Σk ∈ reference qkp; default p = 1

The maximum is taken from the full configured rank table, not reranked inside the selected subset. In the local components table, maximum rank is 115; martinez has rank 63 and sharma rank 17. Hence q values are 53/115 and 99/115, and the normalized reference weights are πmartinez=53/152≈0.349 and πsharma=99/152≈0.651. These are reference weights, not coefficients multiplying the observed losses.

Joint centering across datasets and positions

At deterministic evaluation, let adti be the bounded raw log-gamma score (including log(init_gamma), zero here). Define:

cti = Σk ∈ reference πkakti
mdt = meanvalid i adti; m̄t = Σk ∈ reference πkmkt
gdti = adti − cti − mdt + m̄t
γdti = exp(gdti)

Σd ∈ reference πdgdti = 0 ⇒ ∏d ∈ reference γdtiπd = 1
meanvalid i gdti = 0 ⇒ geometric_meani(γdti) = 1

A gauge is a convention that fixes an otherwise ambiguous reference or scale. These gauges do not set the arithmetic mean of gamma to one. Final mass conservation is a separate normalization of gamma × L.

For each unique transcript, the model repeats its codons under every reference ID and evaluates the bias branch, in reference chunks of at most 32 dataset IDs. No reference target, replicate, or reliability wdt is needed. A reference-only score still receives gradient through the center even when that transcript has no observed loss row in that reference dataset. All reference chunks remain connected to autograd.

Training computes requested scores and reference scores separately. At evaluation, complete requested reference groups can reuse their existing scores, because dropout is off. Otherwise an internal reference forward supplies missing scores. Reference chunking and execution chunking are different controls.

Exactness qualification under dropout: during training, the actual formula is greq = areq − cref − mreq + m̄ref. Independent 0.1 head-dropout draws make requested and reference scores differ. The positional mean-zero identity still follows algebraically, but the weighted cross-dataset mean of the requested g values need not be zero on that stochastic forward. The reported fixed-reference constraint residual is built from the internal reference sums, so a small residual does not by itself verify the requested training rows. Exact deterministic identities apply at evaluation, up to floating-point error.

Raw-score clipping at ±8 occurs before centering. It does not bound the final centered score to ±8: subtraction can expand its range. Conversely, with this finite raw bound, the final gamma is not mathematically unbounded. Clipped raw scores have zero derivative outside the bound.

Source: resolve_gamma_reference_panel, _center_log_gamma_fixed_reference, rank table, gamma background.

12. Replicate counts and consensus play different roles

ȳdti = (1/Rdt) Σr ydtri
Ŝdt = max(meanvalid i ȳdti, ε)
Ŝdtr = max(meanvalid i ydtri, ε)
μdti = Ŝdt hdti → consensus PCC and exported prediction
μdtri = Ŝdtr hdti → raw-replicate NB

The forward exports one shape for each observed pair. The loss broadcasts that same shape and the same positional dispersion across its real replicates. It computes a separate scale from each replicate, so replicate means differ even though their normalized shape and alpha are shared.

Numerical illustration

Suppose two raw replicates are [0,2,4] and [0,6,12]. Their consensus is [0,4,8]; their scales are 2 and 6, while the consensus scale is 4. If the learned mean-one shape is [0.25,0.75,2], the predicted replicate means are [0.5,1.5,4] and [1.5,4.5,12]. The consensus prediction is [1,3,8]. NB sees both raw vectors with their respective means; PCC sees the consensus once.

At fixed α=0.2, the two predicted variances at the last codon are 4+0.2×4²=7.2 and 12+0.2×12²=40.8. Thus shared dispersion does not mean identical count distributions or identical numerical variance.

With mean conservation, each replicate's predicted total equals its observed total, apart from the epsilon floor and numerical precision. If mass_conservation=false, h=gamma×L without final normalization, so its mean is not necessarily one; the observed scale remains an anchor, not an exactly conserved predicted mean.

Source: _compute_replica_loss_terms, replicate-scaling statistical analysis.

13. The complete objective: codons → replicates → datasets → transcripts

13.1 Per-codon NB2 loss

For a raw count y with mean μ and dispersion α, NB2 has variance μ+αμ². The code calls the head output log_sigma, but its likelihood meaning is log α, not log standard deviation.

log α = clamp(log_sigma, −5, 1); α ∈ [0.00674, 2.71828]
κ = 1/α
NLL(y;μ,α) = log Γ(κ) − log Γ(y+κ) + log Γ(y+1)
    − κ log κ − y log μ + (κ+y) log(κ+μ)

The implementation evaluates this in log space with mixed-precision autocast disabled for the loss, floors the likelihood mean at ε=10−8, and excludes padded codons/replicas. There is no active zero-inflation gate. A valid zero contributes an NB term.

13.2 Codon and replicate reductions

f(T) = clamp((T/1000)0.25, 0.5, 2)
NBdtr = f(Tt) × (1/Tt) Σi valid NLL(ydtri; μdtri, αdti)
NBdt = (1/Rdt) Σr real NBdtr

The length factor comes from nb_sequence_reduction=length_tempered, gamma=0.75. It affects NB only. Replicates are averaged, not summed: an extra replicate does not automatically add another full pair-level vote. Longer transcripts receive a tempered NB emphasis rather than strict equality of NB scaling.

13.3 Two pair-level PCC losses

Praw,dt = 1 − PCCvalid i(μdti, ȳdti)
V(x;α) = 2 / √(α+ε) × asinh(√(αx+ε))
PVST,dt = 1 − PCCvalid i(V(μdti;αdti), V(ȳdti;αdti))
ℓdt = NBdt + 0.5 Praw,dt + 0.5 PVST,dt

PCC is epsilon-stabilized Pearson correlation. A PCC component is set to zero loss when its target profile, after that component's transformation, has variance ≤10−6. It is not removed from the outer pair-weight denominator. Alpha in the VST is detached: the alpha head cannot directly lower this loss by changing the transform. Prediction flooring is off. Gamma regularization is off; if enabled it adds its coefficient times the valid-position mean of log(gamma)².

13.4 Reliability within a transcript; equal transcript votes

pdt = wdt / Σk ∈ observed D(t) wkt
ℓt = Σd ∈ observed D(t) pdt ℓdt
Llogical batch = (1/U) Σt in batch ℓt

Example: t1 has pair losses 2 and 6 with weights 1 and 3, so its loss is 5. t2 has losses 3 and 9 with weights 2 and 2, so its loss is 6. The two-transcript batch loss is 5.5. Multiplying every weight of t1 by 100 changes nothing.

Consequential interpretation: wdt determines which dataset to trust for the same transcript. It does not lower a transcript's outer vote when all its datasets have low weights. Nor does a transcript seen in 100 datasets receive 100 times the outer weight of one seen in two. This is a deliberate estimand choice, not equivalent to maximizing the unweighted joint likelihood of all counts.

Two alternatives exist in the reducer: global_weighted takes one weighted mean over all pairs; dataset_balanced first averages by weight inside each represented dataset, then gives datasets equal votes. Execution microbatching explicitly requires transcript_balanced and rejects the other reductions while enabled. Implementation detail: grouped denominators ≤ε are omitted by the reducer, so the ideal formulas assume group weight sums above that threshold.

Source: NegativeBinomialProfileLoss, masked_pcc, reduce_sequence_nll, reduce_per_sample_quantity, _compute_loss_and_metrics, stable NB/VST functions.

14. From execution chunks to one AdamW update

Memory controls do not redefine logical membership

The active execution limits are 512 pair rows and 256,000 padded codon tokens per forward; the group-count cap is null. Padded-token cost is approximated as Bchunk×Tmax,chunk. It is not an exact memory estimator: replicate count, reference evaluations, hidden states, and autograd storage also consume memory.

The sampler preview measures unique transcripts in the actual logical packing before training. It resolves accumulation A from the median group count, without advancing the sampler:

A = clamp(ceil(32 / max(median logical U, 1)), 1, 32)
For ordinary fully paired 32-transcript logical batches: A = 1.
backward_losschunk = Lchunk × Uchunk/Ulogical × 1/A

For a 32-transcript logical batch split into 12/12/8 transcripts, backward weights are 12/32, 12/32, and 8/32. Do not average the three chunk means equally. Summing these scaled losses reconstructs the logical mean for fixed per-transcript evaluations. Dropout draws and floating-point ordering mean chunked and monolithic runs need not follow an identical stochastic trajectory.

One training cycle

Build split → load eligible pairs → preview packing → resolve A
Initialize model, checkpointed reference, AdamW groups, scheduler
For each epoch:
    shuffle order of deterministic logical batches
    For each logical batch:
        For each execution chunk of complete transcript groups:
            collate unique sequences + observed pair rows + raw replicates
            run biology once per unique transcript
            run dataset branch and internal fixed reference
            form consensus mu and replica-specific means
            compute NB + consensus PCC, reduce to transcript-balanced chunk loss
            backward(chunk_loss × chunk_groups / logical_groups / A)
        when A logical batches have contributed:
            clip the complete gradient norm to 1.0
            AdamW.step(); zero gradients
    validate; step plateau scheduler; select checkpoints; check early stopping

This is one AdamW optimizer with three parameter groups, not three alternating optimizers. Manual optimization handles execution chunks; Lightning accumulation stays at one while the module manages logical accumulation. Clipping and weight decay happen at the full optimizer boundary, not separately for each chunk.

Accumulation qualifications: if A>1, logical-batch means receive equal 1/A weight. Individual transcripts therefore have equal weight across the window only when those logical batches contain equal group counts. A final incomplete accumulation window retains 1/A scaling. In single-process mode its flush is in on_train_epoch_end, after validation; the opt-in global mode flushes it before validation. The ordinary A=1 default avoids that remainder-timing issue.

One model across several GPUs

distributed_mode=global_batch preserves the same global logical groups and A, assigning whole transcript groups to workers. It sums gradients across workers at the optimizer boundary, then clips once. There is no extra world-size multiplier in the local loss. This is a custom strategy, distinct from ordinary averaged-gradient DDP and from running independent experiments on separate GPUs. Default execution remains single-process.

CUDA mixed precision runs both GRUs in FP32; other eligible neural operations use BF16. Products and normalizations use stable log-space expressions. context_gru_tbptt_window=0 means full backpropagation; a positive window changes the training gradient by detaching recurrent state across windows, even if the forward sees the full CDS.

Source: training_step, _execution_optimizer_step, configure_optimizers, global gradient strategy, multi-GPU design, GRU precision.

15. Validation, model selection, and prediction

  • Validation: same masks, replica-scale rule, reference panel, and hybrid objective, without gradients or dropout. Current β=0 uses ordinary NB in both training and validation.
  • Epoch loss: transcript-balanced chunk means are logged with unique-transcript counts so unequal chunk sizes do not receive equal weight.
  • Metric distinction: val_mu_pcc is an unweighted consensus-profile PCC mean over observed pairs. It is not the transcript-reliability-weighted objective and does not directly measure recovery of true L.
  • Scheduler: ReduceLROnPlateau monitors val_loss, mode min, factor 0.99, patience 5 validation epochs.
  • Stopping: maximum 200 epochs, early-stopping patience 10 on val_loss; two sanity-validation steps are configured before training.
  • Checkpoints: best val-loss and last checkpoints retain training state. A separate best-PCC checkpoint is selected by maximum val_mu_pcc and stores weights only.
  • Prediction: the default exports separately labeled results from best-val-loss and best-PCC checkpoints, on validation IDs. An external manifest can provide a separate test set.

Sequence-only shared-profile export is available to experiment orchestrators but disabled in the base configuration. L is sequence-only; ordinary exported μ remains conditioned on observed depth. Resuming from a full-state checkpoint preserves optimizer/scheduler state; loading weights alone does not reconstruct Adam moments.

Validation is a selection set. Reusing it for stopping, architecture choices, and final performance reporting does not yield an untouched test estimate. Moreover, the common-to-114-datasets panel measures generalization to a selected overlap population, not to every transcript in the training union.

Source: callbacks and checkpoint-variant prediction, validation_step and _log_stage, prediction field reference.

17. Research concerns and useful experiments

These are implications of the implementation and proposals for testing its assumptions. They are not measured failures or changes made by this report.

ConcernWhy it matters hereUseful response
Panel changes alter training supportThe ≥2-dataset eligibility condition depends on selected datasets. Larger panels can admit different transcripts as well as more measurements of old transcripts.Use matched transcript manifests for panel-size comparisons; report eligible transcript counts and support distributions alongside dataset counts.
Shared biology remains reference-dependentGamma centering imposes a reference convention. A shared sequence-associated artifact can enter L. Independent encoders and good μ fit do not establish causal biological recovery.Compare L across fixed-support reference panels and weights; test recovery against known synthetic L; use external biological validation independent of fitting counts.
Stochastic requested gamma is not exactly centeredRequested/reference dropout draws differ in training, while diagnostics inspect internal reference algebra.Measure the requested-row residual explicitly on complete reference groups. If exact training centering is intended, compare a shared-evaluation implementation or gamma-head dropout=0, with matched runs.
Transcript weights lose absolute reliabilityMultiplying all of a transcript's w values by the same constant cancels. A transcript weak in every dataset retains one outer vote.If scientific goals require transcript confidence, define a separate outer reliability factor and compare it explicitly against equal transcript votes.
Plug-in scale uncertainty is ignoredEach replicate's own mean sets its amplitude, absorbing depth, abundance variation, and sampling fluctuation. Alpha describes residual variation around fitted scales.Compare library-level exposure with a shared transcript amplitude; or, for explicitly conditional allocation, test a count-vector model. Hold shape normalization fixed so only the scale assumption changes.
Replicate averaging changes statistical weightingTwo and ten replicates each yield one averaged NB term per pair; higher-depth counts still affect NB numerically, but there is no automatic replicate-count multiplier.Compare this robust pair-level weighting to a predeclared information-based scheme using synthetic truth and held-out replicate calibration.
Preprocessing references may use held-out profilesThe base run uses stored weights; their depth and median references need not have been fitted on training IDs only.For strict evaluation, fit/freeze references on training IDs via the supported manifest path; separately audit the dataset-quality ranking's provenance.
Fixed length-bucket companionsBatch order changes, but transcripts retain the same batch partners. With AdamW and per-step means, this is not equivalent to uniformly reshuffling transcripts each epoch.First test stability across seeds; if needed, compare an epoch-varying grouping plan that exposes the correct number of chunks and preserves whole groups.
Hybrid loss and clipping complicate dispersion interpretationPCC penalties shape μ; alpha is bounded and learns through a restricted gradient path. It is not a direct empirical replicate-variance estimate.Report alpha-bound occupancy, raw NB diagnostics, calibration on held-out replicates, and shape accuracy separately.
No untouched test set in the base real runValidation is used for scheduler, stopping, checkpoint choice, and default prediction. Transcript-ID separation also does not guarantee gene/family separation.Use a disjoint external test manifest for final reporting; audit gene/homology overlap if sequence transfer is the scientific claim.
Recommended interpretation: this is a jointly trained, reference-anchored model of relative ribosome-profile shape using a hybrid replica-NB/consensus-correlation objective. It should not be described as an unconstrained recovery of uniquely identified biology, an identical-distribution model across raw replicates, or a predictor of unobserved transcript totals.
