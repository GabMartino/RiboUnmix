Stability of the shared profile as dataset number and diversity increase

A reproducible, overlap-controlled experiment asking whether independently trained models converge toward the same sequence-dependent profile \(L_t\) when they receive more heterogeneous Ribo-seq views.

The short answer about equal weighting

“Equal weighting” applies only to the fixed-reference gamma gauge: each selected dataset has \(\pi_d=1/N\) when defining what counts as a shared effect versus a dataset-specific effect. It does not give every observed transcript–dataset pair the same influence on training. Observation quality is still handled separately by the reliability weight \(w_{dt}\).

This choice is necessary for the primary dataset-count experiment because a quality-ranked gamma reference would change both the evidence available to the model and the mathematical definition of \(L_t\) as \(N\) changes. Uniform \(\pi_d\) keeps the reference convention neutral; \(w_{dt}\) continues to tell the loss which measurements are more reliable.

1. Scientific question and model

For dataset \(d\), transcript \(t\), codon position \(i\), and raw replica \(r\), the current model uses the mass-free mean

\[ Y_{dtri}\sim\operatorname{NB2}(\mu_{dti},\alpha_{dti}), \qquad \mu_{dti}=S_{dt}\,L_{ti}\,\gamma_{dti}, \qquad \operatorname{Var}(Y)=\mu+\alpha\mu^2. \]
  • \(S_{dt}\) is the target-derived transcript–dataset mean-count scale.
  • \(L_{ti}\) is the dataset-independent sequence-dependent profile and has valid-position mean one.
  • \(\gamma_{dti}\) is the positive dataset-specific positional observation effect.
  • \(\alpha_{dti}\) is learned NB2 dispersion.

Experiment 8 asks whether two models trained on independently selected datasets produce increasingly similar \(L_t\) as the number of datasets grows. It is a stability/convergence experiment, not a ground-truth recovery experiment. The model trained on all 114 datasets is an empirical reference, not biological truth.

3. Why overlap control is central

If two subsets of size \(N\) are drawn from \(D=114\) datasets, their expected random overlap is

\[ \mathbb E\lvert A\cap B\rvert=\frac{N^2}{114}, \qquad \min\lvert A\cap B\rvert=\max(0,2N-114). \]

At \(N=80\), for example, two subsets must share at least 46 datasets. A high correlation between their learned profiles could therefore reflect shared training data rather than true convergence with dataset count.

Primary statistic

For \(N\in\{2,5,10,20,40\}\), only the designated disjoint A/B comparison is primary:

\[ R_N^{\mathrm{disjoint}} =\mathbb E_p\,\mathbb E_t \left[\operatorname{PCC}\!\left(L_t^{(N,p,A)},L_t^{(N,p,B)}\right)\right]. \]

Full-reference convergence

Every \(N<114\) model is also compared with the one complete-collection solution:

\[ C_N=\mathbb E_a\,\mathbb E_t \left[\operatorname{PCC}\!\left(L_t^{(N,a)},L_t^{(114)}\right)\right]. \]

Every pair of runs additionally receives intersection size, union size, both containment fractions, source-family overlap, expected random overlap, and Jaccard similarity \(J(A,B)=\lvert A\cap B\rvert/\lvert A\cup B\rvert\). Same-\(N\) all-pair agreement is deliberately secondary and is never interpreted without its overlap.

4. How datasets are selected

Source families are indivisible

The implementation reuses the Experiment-1 source-family rule. A non-empty explicit source_identifier is preferred. Otherwise the existing author/year prefix inference is used: a name whose second underscore-separated token contains a digit is grouped by its first two tokens; otherwise it is grouped by its first token. If one dataset in a family is selected, every dataset in that family is selected.

Exact \(N\) is solved under this atomic-family constraint. The default behavior fails clearly if exact cardinality is impossible. Only explicit --allow-nearest-family-size permits a nearest feasible count.

Quality matching uses continuous observed QC—not quality ranking

The full 114-dataset pool defines the target distribution using:

  • log1p_median_read_density;
  • median_positive_codon_coverage;
  • number_of_eligible_transcripts;
  • median_replica_PCC when finite for enough datasets.

Each active variable is median-imputed only where needed and standardized over the full retained pool. For variable (j),

\[ z_{dj}=\frac{x_{dj}-\overline{x}_{\cdot j}}{s_j}. \]

A candidate subset is scored by the root-mean-square discrepancy from the full pool in standardized means and quartiles. Writing \(\Delta\bar z_j\) for the mean discrepancy and \(\Delta q_{j,k}\) for quartile discrepancies,

\[ Q(A)=\operatorname{RMS}_{j,k} \left(\Delta\bar z_j,\;0.5\Delta q_{j,0.25},\; 0.5\Delta q_{j,0.50},\;0.5\Delta q_{j,0.75}\right). \]

For a designated disjoint pair, the joint objective is

\[ Q_{\mathrm{pair}}(A,B)=Q(A)+Q(B) +0.5\operatorname{RMS}_j(\overline z_{Aj}-\overline z_{Bj}). \]

A deterministic randomized dynamic-programming search proposes exact source-family-atomic subsets. The launcher evaluates 2,000 candidate restarts by default and retains the lowest-QC-mismatch candidate. For the primary mode, neither the legacy scalar quality_rank nor a top-\(N\) ordering enters selection. This matters especially at small \(N\): the design seeks a miniature representation of the full quality distribution rather than simply choosing the two “best” experiments.

Where ranking is still used: transcript reliability quantile bins are used only to stratify test/validation transcript sampling, and rank operations are used to compute Spearman correlations. Neither chooses which Ribo-seq datasets belong to an Experiment-8 subset.

5. The two weights—and why they must not be confused

\(\pi_d\): gamma-reference weight

Level: one constant per selected dataset.

Used in: the identification/gauge convention separating shared \(L\) from dataset-specific \(\gamma\).

Experiment-8 value: \(\pi_d=1/N\).

Not used in: NB2/PCC loss weighting.

\(w_{dt}\): reliability weight

Level: one value per transcript–dataset observation.

Used in: the existing transcript-balanced loss reduction.

Experiment-8 value: density/coverage SNR score fitted on training transcripts only.

Can exceed one: yes, after median normalization.

What equal gamma weighting does mathematically

Let \(a^{\mathrm{ref}}_{dti}\) be raw log-gamma for reference dataset \(d\), and let \(m_{dt}\) be its mean across valid positions. The fixed-reference center is

\[ c_{ti}=\sum_{d\in\mathcal R}\pi_d a^{\mathrm{ref}}_{dti}, \qquad m_{dt}=\operatorname{mean}_{i:\,M_{ti}=1}a^{\mathrm{ref}}_{dti}, \qquad \bar a_t=\sum_{d\in\mathcal R}\pi_d m_{dt}. \]

The final requested log-gamma is

\[ g_{dti}=a^{\mathrm{raw}}_{dti}-c_{ti}-m^{\mathrm{req}}_{dt}+\bar a_t, \qquad \gamma_{dti}=\exp(g_{dti}). \]

For the reference panel, this imposes both

\[ \sum_{d\in\mathcal R}\pi_d g_{dti}=0 \quad\text{for each codon }i, \qquad \operatorname{mean}_i g_{dti}=0 \quad\text{for each pair }(d,t). \]

Therefore the weighted geometric mean of gamma across reference datasets is one at every codon, and each dataset–transcript gamma profile also has positional geometric mean one. With equal weights, the cross-dataset center is the ordinary mean of the selected experimental views.

Why equal \(\pi_d\) is the primary scientific choice

  1. It keeps the estimand stable. The experiment should change the number and composition of views, not simultaneously redefine the shared baseline toward whichever datasets have the best external rank.
  2. It separates convention from evidence quality. Gamma centering is an attribution constraint; it is not an estimator of measurement variance. Reliability \(w_{dt}\), raw replicas, and the NB2 likelihood already handle observation quality where it belongs—in the fit.
  3. It prevents double quality weighting. Using a quality-ranked \(\pi_d\) while retaining \(w_{dt}\) would let quality affect both the loss and the definition of the gamma center, via two unrelated mechanisms.
  4. It gives every experimental view one vote in the reference convention. That matches the scientific question about adding heterogeneous views, while the subset sampler keeps their observed QC distributions comparable.
Equal \(\pi_d\) does not assert that all datasets are equally precise. It does not make all pair rows equally influential, erase coverage/depth differences, or bypass NB2 dispersion. It only defines the zero point of log-gamma across the selected reference datasets.

The actual reliability score \(w_{dt}\)

For an eligible transcript–dataset pair, let

\[ D_{dt}=\frac{\text{total reads}_{dt}}{L_t}, \qquad C_{dt}=\frac{\#\{i:y_{dti}>0\}}{L_t}. \]

For each dataset, both references are fitted using its training transcripts only:

\[ \tau_d=\operatorname{median}_{t\in\mathrm{train}}D_{dt}, \qquad q_{dt}=\frac{\sqrt{D_{dt}}}{\sqrt{D_{dt}}+\sqrt{\tau_d}}, \] \[ w^{\mathrm{raw}}_{dt}=0.70q_{dt}+0.30C_{dt}, \qquad w_{dt}=\frac{w^{\mathrm{raw}}_{dt}} {\operatorname{median}_{t\in\mathrm{train}}w^{\mathrm{raw}}_{dt}}. \]

The fitted \(\tau_d\) and normalization median are frozen for validation/test. Held-out rows cannot alter them. Read density is not percentile-ranked, coverage is linear rather than square-root transformed, and median normalization permits reliable observations to have \(w_{dt}>1\).

Why not quality-ranked \(\pi_d\) here?

Quality-ranked gamma centering remains a defensible sensitivity analysis for a different question—for example, defining the shared baseline preferentially by a curated high-quality reference panel. It is not theoretically “wrong.” It is simply a confound in this primary experiment. If used later, it should be a matched ablation with exactly the same subsets and checkpoints clearly labeled as a different gauge convention.

6. Transcript splits and leakage prevention

One common sequence-only test set

The comparison requires identical sequences in every model. If a valid Experiment-1 manifest is supplied, its common test IDs are reused. Otherwise the launcher builds one global test set from sequence-eligible transcripts supported by at least two datasets in the complete 114-dataset universe. It samples 10% after stratification by global median reliability decile and CSS class.

A test transcript does not need two observations inside every tiny subset because \(L_t\) is produced by the sequence-only biological branch. It must, however, be excluded from training and validation in every run.

Run-specific measured validation

Checkpoint selection needs measured profiles. For each subset, validation candidates therefore require at least two usable selected datasets and exclude the common test set. Ten percent are sampled deterministically, stratified by within-run reliability decile and CSS class. Training uses the remaining eligible transcripts, each with support in at least two selected datasets.

Different runs may have different validation counts and training counts. This is intentional and follows observed support in each selected subset. The central cross-model comparison is nevertheless made on exactly the same common test IDs.

8. Post-training measurements

Every best-validation-loss checkpoint exports the common test transcripts with transcript_id, length, \(L_t\), valid-position mask, run ID, \(N\), and subset identity. The analysis asserts identical transcript identities, identical masks, finite values, and valid-position mean \(L_t\approx1\). It does not silently renormalize predictions.

  • Primary disjoint analysis: per-transcript PCC, Spearman, and mean-one RMSE for the 15 designated A/B pairs.
  • Convergence to full: every \(N<114\) run versus the N=114 reference.
  • Secondary all-pairs analysis: same-\(N\) agreement accompanied by actual overlap.
  • Interior robustness: optional metrics excluding the first and last five valid codons, alongside—not instead of—the full-profile metrics.
  • Hierarchy-aware uncertainty: pair-level summaries are retained; bootstrap resampling acts at subset-pair and transcript levels rather than treating codons as independent.
  • Descriptive saturation: an optional monotonic curve summarizes the raw convergence points without presenting its timescale as a biological constant.

Generated figures cover stability versus \(N\), convergence to the full collection, overlap versus agreement, subset quality balance, and deterministic representative transcript profiles. All figure source tables are saved.

Optional diversity hook

A gamma-fingerprint table can supply dataset vectors \(B_d\). The raw subset diversity is the average pairwise Euclidean distance

\[ \Delta(\mathcal D)=\frac{2}{N(N-1)} \sum_{d<e,\;d,e\in\mathcal D}\lVert B_d-B_e\rVert_2. \]

Raw and feature-z-scored versions are reported separately. The default quality_matched experiment does not use fingerprints to select subsets. high_diversity and low_diversity are explicit, non-default confirmatory modes and should not be mixed into the primary curve.

12. How to interpret the eventual result

  • If \(R_N^{\mathrm{disjoint}}\) rises and plateaus, independent experimental collections increasingly identify the same shared profile.
  • If convergence to the 114-dataset solution rises but disjoint stability does not, overlap or a dominant full-panel convention may be contributing.
  • If both remain low, the learned \(L_t\) is sensitive to dataset composition at the tested scale.
  • If quality mismatch explains much of the variation at small \(N\), uncertainty in tiny subsets should be reported rather than hidden.
  • The N=114 profile is never described as truth; it is only the most data-rich empirical reference available in this experiment.
Validated design state (3 September 2026): the full dry run constructed 34 tasks and 561 run-pair overlap records. All 15 designated A/B comparisons had zero dataset overlap and zero source-family overlap; all 114 weighted dataset sources passed preflight. These are design checks, not yet scientific convergence results.
