Mathematics · implementation · translation biology

A useful shared-profile model,
with limits that need to be explicit.

RiboUnmix has a substantial implementation and convincing synthetic results for learning relative sequence-dependent profiles from heterogeneous observations. Its strongest scientific claim is a reference-defined shared representation. Absolute ribosome kinetics, causal technical-bias removal, and a mechanistic queueing interpretation are not established by the current formulation.

Reviewed 5 September 2026 · Working tree based on commit 07872b5, including existing modified and untracked files · Documentation reviewed first, then implementation and artifacts · Analysis only: model, training code, configurations, and datasets were not edited.

1. Overall assessment

The project is worth developing, but “the code runs” and “the decomposition is biologically identified” are different conclusions. The separation of a dataset-blind sequence branch from a dataset-conditioned observation branch is useful. Raw replicates, atomic transcript groups, explicit loss reductions, checkpoint manifests, and held-out panel experiments are meaningful strengths.

The main issues to resolve are the interaction of normalization and identifiability in the mass-free model, stochastic gamma centering during training, incomplete restoration of prediction semantics from checkpoints, and synthetic boundary masking. These have higher priority than making the GRUs larger.

How to read this review. Derived means an algebraic consequence of the equations. Reproduced means a local execution or artifact check. Needs experiment means a plausible improvement whose benefit has not been measured. Recommendations below are proposed changes, not changes already implemented.

2. What the current code actually models

For transcript t, dataset d, replicate r, and codon i, the input contains the CDS sequence and observed count profiles. Let nt be the number of valid modeled codons. The two branches produce:

Shared sequence branch
Codon-derived features → bidirectional GRU → positive local score → within-transcript mean normalization → Lti.
Dataset-conditioned branch
Sequence embeddings + dataset identity → separate bidirectional GRU → raw log-gamma; a detached copy of the context feeds the dispersion head.
Reference-center log-gamma → exponentiate → combine with L and observed mean scale S → predict counts.
Lti = softplus(fθ(Xt)i) / meanj valid softplus(fθ(Xt)j),   meani Lti = 1. gdti = adti − Σe∈R πeaeti − meanjadtj + Σe∈Rπe meanjaetj;   γdti = exp(gdti). Sdt = meani ȳdti,   Sdtr = meani ydtri. Mass-free: μdti = SdtLtiγdti. Mass-conserved: μdti = SdtLtiγdti / meanj(Ltjγdtj).

For the replicate NB term, the model reuses the final inner shape and substitutes the replicate-specific observed mean Sdtr. The consensus mean is used for ordinary prediction and PCC. Replicates therefore do not all receive an identical numerical count mean when their observed totals differ.

The optimized quantity is a hybrid objective

Ydtri ∼ NB2(μdtri, αdti),   Var(Y) = μ + αμ²,   α = exp(clip(log_sigma, −5, 1)). zdt = meanr[τ(nt) meani NLLdtri] + 0.5(1 − PCCraw) + 0.5(1 − PCCVST). τ(n) = clip((n / 1000)0.25, 0.5, 2),   ℒB = meant∈B [Σdwdtzdt / Σdwdt].

This is a useful prediction objective with an NB2 component. Because it also includes PCC penalties, outcome-derived scales and weights, replicate averaging, and length tempering, it should not be described as ordinary joint maximum likelihood for all raw counts. The classical NB2 label correctly describes the local count-loss component when β = 0.

3. Mathematical findings

Priority 1 M1. The mass-free constraints exclude ordinary normalized profiles

Derived + numerical check Suppose the same valid positions are observed in every reference dataset, all πd are positive, and we consider exact, deterministic evaluation. Cross-dataset centering implies Σdπd log γdi = 0. If the mass-free model fit relative expected profiles hdi exactly, then:

hdi = μdi/Sd = Liγdi   ⇒   Li = ∏dhdiπd.

With a scale equal to each noiseless profile's own mean, each target hd has arithmetic mean one. Weighted AM–GM gives:

meani ∏dhdiπd ≤ Σdπd meanihdi = 1.

The inequality is strict when the datasets have different positive relative profiles at any position. Yet the biological branch requires mean(L) = 1. Consequently, the mass-free model cannot exactly fit all such profiles while preserving its constraints. This is a representational restriction, not an optimizer failure. It already follows from cross-dataset centering; the additional positional gamma constraint restricts the family further.

Another view is the model's reference-weighted mass ratio:

Σdπd meani(Liγdi) ≥ meaniLi = 1.

It is strictly above one for nontrivial centered dataset effects where L is positive. Individual datasets may underpredict; the reference-weighted average cannot. This statement concerns the ideal constrained forward function, not the stochastic training draw discussed below.

Recommendation: make the statistical target explicit before another mass-mode comparison. If the goal is relative shape conditional on observed depth, the conserved form is coherent. If the goal is absolute count generation, introduce a separately identified abundance/exposure model rather than taking S from the outcome and interpreting residual mass as recovered abundance. A free pair amplitude could improve fit, but would introduce a new identifiability problem requiring its own constraints.

For the conserved model the corresponding shared-profile identity is L = mean-normalize(∏dhdπd), not the unnormalized identity above. Do not apply the mass-free theorem unchanged to the current base configuration.

M2. A fixed gauge is a definition, not an unbiased estimator of biology

For a fixed collection of model-admitted expectations, centering removes a common multiplicative attribution ambiguity. It does not identify which shared patterns are biological. If every experiment contains the same sequence-dependent distortion, that distortion is indistinguishable from shared biology using these observations alone.

Also, equal weighting across different panels does not keep the finite-panel target identical. Changing panel membership changes the geometric center even when πd = 1/N everywhere. Equal weights preserve a weighting rule; they do not freeze the shared quantity being estimated. Cross-panel stability therefore mixes estimation uncertainty with differences between panel-defined targets.

Repeated conditions from one publication still receive multiple dataset votes in the gamma reference. Consider a source-balanced sensitivity analysis, πd ∝ 1/(number of datasets from source(d)), alongside the current equal-dataset convention. This changes the estimand and must be labeled as such. Missing transcript–dataset pairs also mean that some reference predictions are extrapolated from learned sequence rules, rather than directly constrained by measurements of that transcript.

fixed reference, line 723; Experiment-8 discussion of equal weights; source-family grouping.

M3. Target-derived scale changes the interpretation of inference

Using each target's mean is legitimate for evaluating conditional profile shape if every comparator receives equivalent scale information. It does mean that μ is not a sequence-only prediction of transcript abundance. Replicate-specific scale absorbs observed between-replicate depth differences, so learned alpha describes residual variation after this adjustment, not all sources of replicate variability.

A product of NB probability masses with S recomputed from the same outcome vector is not automatically a normalized joint generative likelihood for that vector. A rigorous shape-only alternative is a conditional count model: for example, conditioning independent Poisson counts on their total yields a multinomial shape likelihood. Overdispersed conditional alternatives require a specified generative construction. Keep absolute-abundance and conditional-shape evaluations separate.

M4. The current VST-PCC can create apparent shape from alpha

Reproduced The transform Tα(x) = 2 asinh(√(αx + ε))/√(α + ε) uses a different alpha at every codon. This is not one common monotone transformation applied along the profile. A spatially varying alpha can create a spatial pattern even when the original counts are constant.

With constant target 3, constant prediction 2, and log-alpha spanning [−5, 1], the existing transform and PCC function return PCC = 0.998797 and mark the comparison valid. The raw target has variance zero. Alpha detachment prevents direct optimization through this PCC term, but does not remove the induced pattern.

Recommendation: apply the raw-target variance validity check to both shape terms; compare the existing VST with a dataset- or transcript-scalar dispersion transform and a fixed log1p/square-root transform. Treat the current score as agreement after position-specific variance adjustment, not pure positional shape. Use held-out accuracy and calibration to decide whether both PCC penalties are worth keeping.

_nb_vst, _pcc_loss_per_sample and masked_pcc; lines 1288, 1296 and 260.

M5. Reliability weighting has a narrower role than its name suggests

The default transcript-balanced reducer gives each transcript one outer vote. Multiplying all its dataset weights by a common positive factor changes nothing. With one dataset, the weight cancels completely. This is an intentional estimand choice, not a loss bug; it means “reliability” primarily chooses between datasets for the same transcript.

Dataset-median normalization of the SNR score further removes much of the absolute depth scale. A uniformly shallow dataset need not get smaller normalized weights than a uniformly deep dataset. NB2 already makes information depend on mean and dispersion; extra weights are a heuristic preference, not calibrated inverse-variance weights.

Estimate the effective number of views for each transcript, Neff,t = (Σdwdt)² / Σdwdt², and report support and depth alongside it. Replica counts and shared-source dependence require additional treatment; this formula alone does not measure independent biological information.

4. Is the code correct?

Much of the core implementation is carefully protected, but there are specific correctness and reproducibility gaps. The following findings distinguish behavior reproduced in the current tree from risks inferred from the source.

Priority 1 C1. Training dropout breaks the reported gamma constraint

The requested rows and reference rows are evaluated separately during training. The gamma head has dropout 0.1. The centering calculation therefore subtracts a center formed from a different stochastic realization. Within-profile centering still holds, but the requested reference rows need not satisfy the cross-dataset constraint.

Reproduced This used the actual modules with reduced hidden widths, two equal-weight reference datasets, seed 23, and a nonzero gamma-head weight to exercise behavior after neutral initialization. It was not a measurement from a trained production checkpoint.

The diagnostic currently evaluates an algebraic cancellation of its own reference sums. It does not establish that the separately evaluated requested outputs satisfy the constraint. In training, exponentiation also converts zero-mean log noise into a non-neutral expected multiplicative effect.

Fix direction: compute reference scores once per transcript and gather observed reference rows from the same stochastic tensor, including their attached gradient paths. Alternatively, make the gamma-score path deterministic. Evaluate missing/non-reference rows explicitly. Add a test with nonzero head weights and active dropout; the deterministic centering tests do not exercise this failure.

reference reuse is evaluation-only, lines 861–958; diagnostic, line 987; gamma-head dropout; existing deterministic centering tests.

Priority 1 C2. Strict checkpoint loading does not restore the mass mode

Reproduced mass_conservation is a Python attribute and is absent from get_extra_state(). Loading a mass-free model's state into an otherwise identical conserved model succeeds with “All keys matched successfully,” yet the receiver remains conserved and gives different count predictions.

The small probe produced a maximum prediction difference of 5.26 × 10−5 because its gamma effects were deliberately small. The important result is the silent change of function; the size depends on the checkpoint. The Lightning module also excludes the config from saved hyperparameters, and load_weights_only() does not reconstruct it from the saved resolved YAML.

Fix direction: persist and validate all function-defining settings: mass mode, feature routing/scales, position conventions, encoding identity, alpha bounds and relevant loss semantics. Pair the checkpoint with a versioned configuration and input-schema hash. Test that loading under a contradictory config either restores the original function or fails clearly.

Separately, from_checkpoint=true before training loads weights and starts a fresh optimizer/scheduler. It is a warm start, not an exact training resume. That behavior is documented in the loader but should be explicit in launcher names and experiment provenance.

get_extra_state, line 315; save_hyperparameters, line 725; load_weights_only, line 1099; training restart, line 2585.

Priority 1 C3. An artificial synthetic terminal zero is treated as data

The synthetic preprocessor appends a zero when the count profile is one position shorter than the CDS. The collator then constructs the mask solely from sequence length. Thus the appended terminal position is valid for NB2, consensus PCC, observed scale, and normalization.

This supervises an unobserved position as a measured zero and changes every transcript's scale/normalization slightly. Excluding boundaries in the later recovery report does not remove their influence during training.

Fix direction: carry an observation mask separately from sequence/context validity. Retain the stop codon as context if desired, but exclude a synthetic placeholder from likelihood and target-derived scale. Specify whether biological/gamma normalization is over physical observed positions or the complete modeled CDS and align the truth accordingly. Do not simply introduce an internal hole in the packed-GRU mask; sequence packing assumes valid prefixes.

_validate_and_pad, lines 64–96; collate_fn, mask construction near line 1092.

Things the implementation already does well

  • Packed bidirectional GRUs prevent right-padding from contaminating backward sequence context.
  • The shared biological GRU runs once per unique transcript under the default zero-dropout setting; gathering outputs preserves gradients from all dataset rows.
  • Raw replicas remain separate for NB2; the consensus is used once per pair for each PCC component.
  • Gamma reference membership and weights are checkpointed; evaluation does not require co-resident partner datasets.
  • Optimizer parameter groups check completeness and uniqueness; fixed-alpha parameters are excluded, and nonfinite gradients fail before the update.
  • The current sampler keeps physical packing deterministic and shuffles complete logical batches, addressing the historical changing-epoch-length failure visible in an older real-panel log.

7. Biological interpretation: what can be extracted?

The most defensible output is a relative, sequence-dependent ribosome-footprint profile that is shared under a specified dataset reference. Biological interpretation becomes stronger when it survives independent panels, matched technical comparisons, independent annotations and perturbations.

“Queueing” is currently an analogy, not an identified mechanism

The biological model applies softplus and mean normalization to a neural score. There is no fitted initiation rate, service/elongation rate, exclusion interaction, or continuity equation linking adjacent codons. The algebraic identity ρ = L/(1 + L) can resemble a queue formula without making the learned variables physical queue parameters.

J = meani log(1 + Li) ≤ log(1 + meaniLi) = log 2.meani ρi ≤ 1/2.

These bounds follow from concavity and mean-one normalization. A flat profile maximizes J at log 2; concentrating the same relative mass lowers it. J is a profile-shape summary, not ribosome flux. Inferring residence times from occupancy would require additional assumptions such as steady state, known flux and negligible traffic; those assumptions are not enforced here.

Repository: forward, lines 99–137. Biological context: Meydan & Guydosh, disome/trisome profiling (2020) directly studies collision-sensitive measurements and their dependence on translation dynamics.

Biological catches that matter for this particular project

  • Nuclease effects can change local profiles even when gene-level measurements agree. This is a good motivation for gamma, but it requires testing whether the learned signature matches independently documented protocol variation. Gerashchenko & Gladyshev (2017).
  • Cycloheximide interpretation is organism- and protocol-dependent. Yeast experiments show redistribution biases, while a human-focused study reports resistance to several such effects. A CHX-associated gamma signature is not automatically a universal artifact mechanism. Hussmann et al. (2015); Sharma et al. (2021).
  • Polyproline is a useful predefined validation target, with context. eIF5A-dependent translation of polyproline gives a mechanistic reason to examine these motifs. It does not imply that every PP/PPP occurrence must produce a large pause in every dataset. Match sequence context and test perturbations where available. Gutierrez et al. (2013).
  • CDS-only inputs omit footprint-end context at boundaries. The saved synthetic boundary analysis inferred required offsets −12/−11 and +16/+17 relative to the P-site codon start. A GRU cannot determine unseen UTR nucleotides exactly. Add matched transcript flanks and explicit unknown tokens, or restrict exact-recovery claims to observable windows. That flank-complete recovery experiment has not been established by the reviewed artifacts.
  • Codon aggregation hides upstream processing uncertainty. The pipeline starts from aligned count parquets. It does not independently validate raw read-length distributions, frame periodicity, multimapping, or per-length P-site offsets. Protocol-induced coordinate shifts may be absorbed into gamma or alpha rather than identified as shifts.
  • Sequence-only predictions cannot respond to an unencoded biological state. The same sequence gets the same shared L whether tRNA availability or cellular stress changes. Dataset-conditioned differences can capture those effects, but then gamma includes genuine biology. Unseen dataset identities need calibration or a metadata-conditioned model; an unused embedding is not a scientifically validated new protocol.

Boundary evidence: existing boundary investigation. Scope follows the CDS sequence builder and parquet input interface.

The within-depth gamma table has 27 panels with log-gamma Fisher PCC from 0.996008 to 0.999722 and mean log-RMSE from 0.008908 to 0.026545. That is strong evidence that the model can learn the programmed relative bias contrasts in this synthetic setting.

Two qualifications are essential. The kinetic reference is a deterministic programmed relative-residence profile; its documented metadata exclude TASEP exclusion and Gillespie sampling. These experiments do not validate ribosome traffic dynamics. Also, the modern gamma analysis re-centers both learned and true log-gamma over the evaluated interior. Its excellent metrics validate those projected contrasts, not raw multipliers, full-CDS normalization, or the absence of the mass-mode conflict.

The cross-depth equal-versus-rank table contains ten comparable pairs. Small differences in L recovery are descriptive; changing gamma weights changes the reference and gradient coupling even though those weights do not directly enter the loss. Similar L scores in this particular dataset are empirical, not a mathematical guarantee of invariance.

Limits of the current evidence

  • Ordinary synthetic studies report validation predictions selected using that validation set, not a locked independent test result.
  • A cumulative panel changes bias identity together with dataset count. One order and one training seed do not identify a pure causal effect of N.
  • Increasing dataset count also changes the reference target. Add an oracle gauge-compatible shared target alongside physical K to separate estimator error from reference mismatch.
  • Fisher weights n − 3 assume more independence than adjacent codons and shared-transcript datasets usually provide. These summaries are useful descriptively; their apparent precision is not independent-experiment precision.
  • The absence of a matched conserved/mass-free pair means the current synthetic results cannot resolve M1 empirically or establish that mass-free is superior.

9. A stronger validation design

  1. Lock the unit of generalization. Create an untouched test partition before architecture/loss selection. Split by gene or sequence-similarity cluster where possible, not just transcript ID; transcript-disjoint sets can still contain highly related sequences. Report sparse/rare transcripts separately from the master-common validation intersection.
  2. Freeze preprocessing on training IDs. The real panel/Experiment-8 workflows already fit reliability references on training IDs. Extend that practice to ordinary real, synthetic and benchmark workflows. Outcome-based stratification is not direct label injection into the network, but it selects the evaluation population and should be reported.
  3. Run a small matched correctness matrix first. Identical panels, seeds, masks and training budget: conserved versus mass-free; coherent versus independent-dropout reference evaluation; observed-only versus appended-zero supervision; scalar versus position-specific VST alpha. Report mass ratios, raw NB2, shared recovery and gamma recovery separately.
  4. Use genuinely competitive baselines. Compare gamma = 1, a direct sequence-to-profile model with matched backbone/scale handling, a zero-aware/shrunk geometric-consensus baseline, a sequence model trained on that consensus, and a simpler local sequence model. An empirical geometric mean on test-transcript measurements has extra input information; label it as a transductive denoising comparator, not an equivalent sequence-only predictor.
  5. Separate seeds, sources and transcript uncertainty. Repeat initialization seeds within fixed panels and panel selections within fixed N. Bootstrap source/panel and transcript levels; use block-aware positional diagnostics. Three subset pairs provide limited evidence about a distribution of possible experiments.
  6. Calibrate uncertainty on unseen measurements. Hold out a replicate where available; predict it using an explicit depth convention. Check randomized quantile residuals or predictive intervals, zero-count frequency, dispersion by depth, and residual autocorrelation. Ensembles address parameter/panel uncertainty that alpha cannot.
  7. Make biological controls independent. Validate CSS alignment and source independence, use matched negatives and precision–recall as well as recall, and account for transcript clustering. For motifs, predefine offsets and windows; compare synonymous/codon/GC/length-matched backgrounds and replicate the effect across source-disjoint models.
  8. Add the missing context before claiming boundary recovery. Supply isoform-matched UTR flanks for the sequence window used by the synthetic generator. Keep output coordinates unchanged and test a fixed-alpha control first. For traffic claims, add independent disome/runoff/kinetic evidence and an explicit traffic model.

The default intersection-based validation panel favors transcripts detectable in every master dataset. That makes subset comparisons convenient but does not represent all transcripts encountered at deployment. The newer sequence-only common test path helps broaden support, but source selection, gene similarity, and biological context still need their own controls.

Reproduce the central algebra and VST checks

Run from the repository root in the existing environment. These checks construct small tensors and do not train or change data.

import numpy as np
import torch
from Models.RiboUnmixLightningModule import masked_pcc

# Exact normalized profiles with complementary dataset effects.
h = np.array([[1.5, 0.5], [0.5, 1.5]])
center = np.exp(np.log(h).mean(axis=0))
L = center / center.mean()
gamma = h / center
mass_free = L * gamma
mass_conserved = mass_free / mass_free.mean(axis=1, keepdims=True)
print(center.mean())                # 0.8660254038, not 1
print(mass_free.mean(axis=1))        # [1.15470054, 1.15470054]
print(np.allclose(mass_conserved, h))  # True

# Position-specific alpha induces a pattern in otherwise flat profiles.
alpha = torch.exp(torch.linspace(-5, 1, 30))[None, :]
vst = lambda x: 2 / torch.sqrt(alpha + 1e-8) * torch.asinh(
    torch.sqrt(alpha * x + 1e-8))
out = masked_pcc(vst(torch.full_like(alpha, 2.0)),
                 vst(torch.full_like(alpha, 3.0)),
                 torch.ones_like(alpha, dtype=torch.bool),
                 min_target_var=1e-6, eps=1e-8)
print(out["pcc_per_sample"], out["valid"])  # approximately 0.998797, True
