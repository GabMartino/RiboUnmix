# Partial stability results

For the experiment design, ranking formulas, training procedure and evaluation
definitions, read the [HTML methodology report](stability_experiments_methodology.html).

**Cohort correction:** read the [split audit and corrected experiment](cumulative_cohort_audit_and_correction.html).
The legacy cumulative setup resampled training and validation membership across N.
Within-model folds are disjoint, but those runs do not isolate dataset addition
with fixed training transcripts. A fresh seed-42 setup now fixes 5,714 training,
714 validation and 714 test transcripts across all 114 datasets and every N.

For the interpretation of gamma=1, the latest component evidence and a proposed
gamma fingerprinting experiment, read the [component evidence report](stability_component_evidence.html).

From the repository root, run the two CPU-only analyses:

```bash
python analyses/analyze_cumulative_reference_weight_stability.py
python analyses/analyze_four_panel_stability.py
```

Use the project environment (`.venv/bin/python` locally). Both scripts accept
`--experiment-root /path/to/downloaded/experiment` and resolve the saved cluster
paths relative to that experiment directory. No training or prediction is launched.

Both scripts now audit the saved transcript folds and export `fold_audit.csv`
and `fold_pair_audit.csv`. Each requires a common test set and disjoint roles
within every model. The four-panel analysis additionally requires common
validation IDs; the corrected cumulative design requires identical training IDs too.

| Script | Primary comparison | Observed-profile metrics |
| --- | --- | --- |
| `analyze_cumulative_reference_weight_stability.py` | L_bio across adjacent N and against N=2, on common test sequences. | Shows the cached fixed-observation test figure when available, links every dataset's curve, and keeps training validation curves in an expandable diagnostic section. |
| `analyze_four_panel_stability.py` | L_bio across the six panel pairs, including full versus gamma=1. | Logged validation fit only; effective observations differ by dataset, and different panels have different dataset identities. |

The cumulative default still reads the legacy experiment. Analyze the newly
prepared controlled experiment with:

```bash
python analyses/analyze_cumulative_reference_weight_stability.py --experiment-root results/cumulative_stability_fixed_cohort_seed42
```

Changing an analysis script or its output root does not retrain checkpoints.
The four-panel held-out roles already stay fixed, but training eligibility varies
across panels. Its L_bio comparisons describe reproducibility across the fitted
collections; they do not isolate dataset composition with identical training transcripts.

## Reports

- [Cumulative stability](../analyses/artifacts/real_data/cumulative_stability/analysis_report.html)
- [Cumulative observed fit on identical held-out observations](../results/cumulative_stability_seed42/fixed_observed_evaluation/analysis_report.html)
- [Four-panel stability and gamma=1 ablation](../analyses/artifacts/real_data/four_panel_stability/analysis_report.html)

Each report includes a timestamp, artifact availability, measured interpretations,
validation-progress plots, and downloadable metric tables. Re-run the same command
after copying additional model outputs. The analysis does not query Slurm; a saved
`running` status is a snapshot, and missing local artifacts do not establish failure.

The cumulative report compares only the planned adjacent sizes and separately
shows drift from N=2. It never substitutes a larger available endpoint for a missing
size. The four-panel report compares the six panel pairs and reports full-versus-
shared-only effects only when both endpoints are present for both models.

The cumulative report's expandable **training validation diagnostics** plot
PCC(μ, observed), PCC(L_bio, observed), and their difference as N grows,
at each exported best-validation-loss checkpoint.
Both metrics first average the same validation pairs within each dataset and then
average dataset means equally. It shows all N datasets and, separately, the fixed
best-two dataset identities; validation transcripts still change with N in both.
Missing per-dataset tags leave a gap instead of silently changing the averaging
set. `observed_fit_summary.csv` and `observed_fit_per_dataset.csv` record the
values, coverage and log provenance. A separate plot tracks L_bio variance on the
common test transcripts. These additions are regenerated by the same command.

The **individual-dataset μ PCC** section shows each dataset's curve across N,
with all five policies, a dataset selector, exact values, and an overview containing
one panel per dataset. Every panel uses the same PCC scale and follows the frozen
quality-rank order. `dataset_mu_pcc_overview.pdf` contains all available panels;
`dataset_mu_pcc_grid.csv` distinguishes values, datasets not yet included, missing
models and missing μ tags. A μ PCC is shown even when the L_bio diagnostic is absent.
Datasets with only one completed N have points without an inferred trajectory.

Inter-model PCC, RMSE and peak-overlap metrics use explicitly recorded finite transcript
cohorts. Comparisons condition on one training seed. Six pairs sharing models are
not six independent training repetitions. Validation metrics were used to select
checkpoints; sequence-only test exports contain dummy count targets and cannot
provide independent count-reconstruction accuracy.

Observed-profile PCC follows the saved training diagnostic convention, including
zero for near-constant profiles. Its per-dataset means cannot be filtered back to
a fixed transcript subset from TensorBoard alone. A fair across-N observed test
curve now uses separate inference on the same real held-out transcript–dataset pairs:

```bash
python analyses/reevaluate_cumulative_fixed_observations.py
```

This uses the same 704 original test transcripts observed in all 114 datasets,
with original best-validation-loss checkpoints, real replica consensus targets,
identical CDS masks and equal transcript weights. It writes per-pair metrics,
per-dataset curves, an HTML report and the fold audit in
`results/cumulative_stability_seed42/fixed_observed_evaluation`.
The cohort stays fixed as new checkpoints arrive. Cached metrics are reused only
when their scientific inputs match. This repairs evaluation, while the original
training-cohort differences remain in the existing checkpoints.

For fresh controlled training, submit `sbatch run_cumulative_fixed_cohort_univie.slurm`.
Its default output is `results/cumulative_stability_fixed_cohort_seed42`;
both analysis commands accept that directory through `--experiment-root`.
Generate the setup on the cluster instead of copying locally prepared absolute paths.
The corrected complete-case cohort studies broadly observed transcripts and has
fewer training transcripts than the legacy setup.

`availability.csv` records rejected/missing artifacts; `comparison_readiness.csv`
identifies missing endpoints; `metric_cohorts.csv` records exclusions. Per-transcript
metrics, paired effects and report checksums are saved alongside each HTML report. No effect
is imputed for missing models, and the selected cohort can change as more valid
models arrive, so retain a report snapshot when citing its numbers.
