Separating dataset-selection order from reference-weight direction

Audit result: the historical reverse_p1 and reverse_p3 arms did not select the worst datasets first. They retained each best-N collection and reversed only the gamma-reference weight vector inside that collection.

What the old reverse control actually tested

The cumulative runner first sorted all configured datasets from best to worst and selected names[:N]. It then constructed quality weights and, for a reverse arm, applied raw[::-1]. Therefore ranked and reverse arms had exactly the same dataset membership.

DN = the N best datasets for every old arm
ranked: larger π goes to better datasets in DN
reverse: the same π multiset is reassigned so larger π goes to worse datasets in DN

This is a valid control for the direction of gamma-reference weighting. It cannot test the effect of training first on the worst datasets or replacing a high-quality collection with a low-quality collection. The old four-panel experiment similarly kept each panel fixed and changed only π.

The N=114 endpoint is trained once per reference policy and shared by both paths. This avoids wasting two GPU runs on identical configurations and makes convergence at the full collection explicit.

Primary condition: equal gamma-reference weights. The direct best-N versus worst-N comparison therefore changes dataset membership while holding the reference formula uniform. Secondary condition: the prespecified global q³ reference inside each selected collection. Because absolute q values are much smaller in the worst collection, q³ concentration is different there; this secondary curve tests the combined membership/reference intervention and is not the clean membership contrast.

The main measurements are:

  1. Direct PCC and RMSE between best-N and worst-N Lbio on the same transcripts.
  2. Agreement of every model with one shared best-N=2 equal-reference anchor.
  3. Adjacent changes along the best-first and worst-first paths.

Best and worst collections are disjoint through N=40, begin overlapping at N=80, and are identical at N=114. Their separation should therefore be largest before overlap and must disappear at the full-set endpoint. Expecting divergence to increase monotonically through N=114 would contradict the design.

New four-quality-strata experiment

The four panels are now contiguous blocks in the active quality ordering, rather than four mixed-quality collections:

The primary result compares each equal-reference panel with q1_best. A progressive PCC decrease and RMSE increase from Q1 to Q4 would directly support sensitivity of Lbio to the quality composition of the training collection. The q³ model in each panel is a secondary within-panel reference sensitivity.

Transcript control

Both experiments use the intersection of transcripts with usable observations in all 114 configured datasets and partition it once:

FoldTranscriptsReuse
Training5,714Identical at every N, direction, stratum and policy
Validation714Identical everywhere
Test714Identical IDs and CDS coordinates everywhere

Each dataset's reliability reference is fitted once on those 5,714 shared training IDs and reused wherever that dataset occurs. This removes the training/validation membership and changing-reliability-fit confounds found in the legacy cumulative experiment. The complete-case cohort favors broadly observed transcripts, so generalization beyond that cohort remains a limitation.

What the experiment can establish

A best-versus-worst difference establishes that the QC-ranked dataset composition affects the learned decomposition. It does not by itself show that the best-N profile is biologically correct: the QC score is a proxy, the N=2 model is noisy, and related datasets may occur in more than one quality stratum. Biological correctness still requires synthetic known-signal recovery or an external experimental endpoint.
