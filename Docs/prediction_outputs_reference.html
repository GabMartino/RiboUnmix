Prediction outputs: field-by-field reference

This page describes the schema produced by the current predict_step() and predictions_to_parquet() implementations. It covers the ordinary 40-column prediction parquet and the compact 8-column Experiment-8 shared-profile parquet.

Files Main 40 columns Compact \(L_t\) Sequence-only warning Reading example

1. Which prediction file is which?

FileContents
predictions_main_val_best_val_loss_*.parquet Validation predictions loaded from the checkpoint with minimum validation loss.
predictions_main_val_best_pcc_*.parquet Validation predictions loaded from the checkpoint with maximum validation \(\mu\)-PCC, when that checkpoint was requested and saved.
predictions_main_test_*.parquet The same schema evaluated on an explicit test fold. Experiment 8 uses this form.
common_test_L_profiles.parquet Compact, one-row-per-transcript \(L_t\) export from the best-validation-loss checkpoint.
common_test_L_profiles_best_pcc.parquet Compact \(L_t\) export from the PCC-best checkpoint, only if that variant was explicitly requested.
prediction_checkpoint_manifest.json Maps each requested checkpoint variant to its exact checkpoint and prediction artifact.
In ordinary prediction, one row represents one eligible transcript–dataset pair, so a transcript can appear once per selected dataset. In Experiment-8 sequence-only prediction, there is one dummy interface row per held-out transcript; the compact \(L_t\) file is the scientific artifact.

Every stored positional vector is trimmed to length. Batch padding is not written to parquet, and vector element \(i\) refers to the same modeled codon in every positional column.

2. Main prediction parquet: all 40 columns

Identity, sequence, and metadata

ColumnTypeExact meaning
transcript_idstringTranscript identifier, including the version suffix where present.
idsstringCompatibility alias of transcript_id; the two values are identical.
dataset_idintegerEncoded dataset identity. Convert it back with the inverse of Datasets/encodings/dataset_encoding.yaml; the parquet does not contain a dataset-name column.
lengthintegerNumber of valid modeled codon positions stored in this row.
lengthsintegerCompatibility alias of length.
csslist or nullConserved-stalling-site indices inherited from the sequence table. Current analyses interpret them directly as zero-based indices into the modeled codon vectors. Null means no annotation.
maskboolean vector [L]Valid-position mask. Because vectors are trimmed to length during export, it is normally all true; it is retained for explicit alignment checks.
codon_idsinteger vector [L]Codon at every position, encoded with Datasets/encodings/codon_encoding.yaml.
sample_weightfloatThe transcript–dataset reliability weight \(w_{dt}\) used by the configured loss reduction. It is median-normalized and may exceed one.
dataset_quality_rankfloatDataset-level quality rank; rank 1 is best. It can be NaN when no ranking exists, as in some synthetic data.
dataset_quality_weightfloatRank-derived metadata \((R-r_d+1)/R\). It is distinct from sample_weight. Under Experiment-8 equal fixed-reference centering, it does not weight gamma or the loss.

Observed target and predicted mean

ColumnTypeExact meaning
targetfloat vector [L]Arithmetic consensus of the raw replica count profiles for this transcript–dataset pair. Individual replica vectors are used by the NB2 loss but are not exported here.
mufloat vector [L]NB2 mean prediction \(\mu_{dti}\). In the active mass-free model, \(\mu_{dti}=S_{dt}L_{ti}\gamma_{dti}\).
likelihood_positive_meanfloat vector [L]Current likelihood-safe mean. Despite the historical name, the current NB2 implementation is not zero-truncated and this is normally identical to mu after finite-value handling and the positive epsilon floor.
scale_dtfloat\(S_{dt}\), the mean of target over valid positions.
normalized_shapefloat vector [L]The inner mean shape before multiplication by \(S_{dt}\). With mass_conservation=false, it is \(\gamma_{dti}L_{ti}\) and need not have mean one. With mass conservation enabled, it is divided by its valid-position arithmetic mean.
\[ \texttt{mu}=\texttt{scale\_dt}\times\texttt{normalized\_shape}. \]

Shared biological branch

ColumnTypeExact meaning
L_biofloat vector [L]The shared, dataset-blind sequence prediction \(L_{ti}\). It is positive and normalized to valid-position arithmetic mean one independently for each transcript.
rho_biofloat vector [L]Bounded transform \(\rho_{ti}=L_{ti}/(1+L_{ti})\). It contains no information beyond \(L_{ti}\).
JfloatDiagnostic transcript summary \(J_t=\operatorname{mean}_i[\log(1+L_{ti})]\). It is not a separately learned flux parameter and does not enter the prediction equation.

Dataset-specific gamma branch

ColumnTypeExact meaning
log_gamma_rawfloat vector [L]Raw dataset-branch log score before cross-dataset and positional gauge fixing.
gamma_rawfloat vector [L]\(\exp(\texttt{log\_gamma\_raw})\). This is ungauged and should not be used as the final bias estimate.
log_gammafloat vector [L]Final gauge-fixed log correction \(g_{dti}\).
gammafloat vector [L]Final positive correction \(\gamma_{dti}=\exp(g_{dti})\). This is the gamma quantity to use for interpretation and synthetic recovery.
gamma_cross_dataset_log_centerfloat vector [L]The cross-reference log center \(c_{ti}\) subtracted from the raw score. The additional within-pair positional shift is not exported as its own column, so this field alone is insufficient to reconstruct final log_gamma.
additive_biasfloat vector [L]Compatibility placeholder. The current mean model is purely multiplicative, so this column is zero.

Gamma-centering diagnostics

ColumnTypeExact meaning
gamma_centering_reliabilityfloat vector [L]Normalized gamma-centering weight assigned to the requested dataset/row. In Experiment-8 equal fixed-reference mode it is \(1/N\). Despite its name, it is not the observation reliability sample_weight.
gamma_centering_eligibleboolean vector [L]Positions with valid inputs that are eligible for the centering calculation. Eligibility does not necessarily imply that centering was applied.
gamma_centering_appliedboolean vector [L]True where the configured cross-dataset gamma center was actually applied.
gamma_num_distinct_datasetsfloat vector [L]Number of distinct datasets contributing to the center at each position. In active fixed-reference mode this normally equals the reference-panel size.
gamma_total_reliabilityfloat vector [L]Sum of the raw gamma-reference weights. With equal raw weights it equals \(N\). It is not a sum of transcript reliability weights.
gamma_centering_constraint_errorfloat vector [L]Absolute residual of the weighted cross-dataset log-gamma constraint; values near zero indicate numerically successful centering.
gamma_centering_modestringConfigured mode, currently one of fixed_reference, batch_grouped, or disabled.
gamma_reference_dataset_countfloatNumber of datasets stored in the fixed reference panel.
gamma_reference_dataset_idsinteger listEncoded IDs of the fixed reference datasets. Due to scalar simplification by the serializer, a one-dataset panel can appear as a scalar rather than a length-one list.
gamma_reference_manifest_hashstringSHA-256-like identity of the resolved reference membership and weighting convention, used for reproducibility checks.
gamma_reference_weightingstringequal or quality_rank; describes only the gamma gauge.
gamma_reference_quality_rank_powerfloatExponent applied to rank-derived reference weights. It has no effect when weighting is equal.
gamma_reference_chunk_sizeintegerNumber of reference identities evaluated per internal forward chunk. This affects memory/runtime, not the mathematical center.
gamma_all_requested_in_referencebooleanWhether the requested dataset identity belongs to the stored fixed reference panel. False indicates extrapolation or a centering fallback.

NB2 dispersion

ColumnTypeExact meaning
log_sigma float vector [L] Historical name for the alpha-head output. It is interpreted by the likelihood as log NB2 dispersion, not log standard deviation. The likelihood first clamps it to the configured nb_log_alpha_min/max, then uses \(\alpha=\exp(\operatorname{clip}(\texttt{log\_sigma}))\). The current defaults are \([-5,1]\); inspect the run's resolved configuration before deriving alpha.
There is currently no separate alpha column. Do not blindly calculate exp(log_sigma) without applying the loss bounds if you want the dispersion actually used by NB2.

3. Compact Experiment-8 shared-profile file: all 8 columns

common_test_L_profiles.parquet is deliberately small and contains exactly one row for every common held-out transcript.

transcript_lengthintegerNumber of valid modeled codons.
L_tfloat vector [L]Direct copy of L_bio, the shared sequence-only mean-one profile used for cross-model comparisons.
valid_position_maskboolean vector [L]Mask that must be identical between runs before comparing positions.
run_idstringExperiment task identifier, such as real_exp8_N020_pair02_A.
Ninteger or nullNumber of selected training datasets, supplied by the Experiment-8 orchestrator.

L_meanfloatAudited mean of L_t over valid positions; it must be within \(10^{-4}\) of one.

4. Critical Experiment-8 sequence-only distinction

In Experiment 8, the dataloader inserts one all-ones dummy profile and one dummy selected-dataset identity solely to pass a held-out sequence through the existing prediction interface. Therefore the large predictions_main_test_*.parquet must not be interpreted as an observed test-profile reconstruction.
Meaningful in sequence-only modeDummy-dependent; do not use scientifically
transcript_id, ids, length, lengths, css, mask, codon_ids, L_bio, rho_bio, and J. target, dataset_id, sample_weight, dataset-quality fields, scale_dt, mu, normalized_shape, gamma fields, alpha/log_sigma, and their centering diagnostics.
For Experiment-8 convergence analysis, read common_test_L_profiles.parquet. The checkpoint manifest also records observation_dependent_dummy_outputs_are_scientific: false.

5. Prediction checkpoint manifest

prediction_checkpoint_manifest.json contains one top-level object per requested variant: best_val_loss and optionally best_pcc. Each object records:

EntryMeaning
checkpoint_pathExact checkpoint loaded before prediction.
output_pathMain 40-column parquet path.
shared_profile_output_pathCompact \(L_t\) path, or null when sequence-only export was disabled.
prediction_rowsNumber of rows written to the main parquet.
split_nameval or test.
transcript_countNumber of transcript IDs requested for that split.
transcript_id_hashStable hash for checking identical prediction transcript sets.
sequence_only_shared_profile_predictionWhether the dummy-interface sequence-only path was active.
observation_dependent_dummy_outputs_are_scientificExplicitly false for the current sequence-only export.

Nearby JSON files are provenance rather than prediction columns: gamma_reference_manifest.json defines the gamma gauge; loss_reduction_manifest.json records the objective; split_manifest.json records folds; and grouped_optimizer_batch_plan.json records batch packing and accumulation.

6. Minimal safe reading example

from pathlib import Path
import numpy as np
import pandas as pd
import yaml

prediction = Path(".../predictions_main_val_best_val_loss_....parquet")
df = pd.read_parquet(prediction)

# Resolve integer dataset IDs.
name_to_id = yaml.safe_load(
    Path("Datasets/encodings/dataset_encoding.yaml").read_text()
)
id_to_name = {int(value): name for name, value in name_to_id.items()}
df["dataset_name"] = df["dataset_id"].map(id_to_name)

# Dispersion actually used by the current default NB2 likelihood.
df["alpha"] = df["log_sigma"].map(
    lambda x: np.exp(np.clip(np.asarray(x, float), -5.0, 1.0))
)

# Every positional output in one row must align.
row = df.iloc[0]
assert len(row["mu"]) == row["length"]
assert len(row["L_bio"]) == row["length"]
assert len(row["gamma"]) == row["length"]
assert np.allclose(
    row["mu"],
    row["scale_dt"] * np.asarray(row["normalized_shape"]),
    rtol=1e-4,
    atol=1e-6,
)

Replace the hard-coded alpha bounds with values from the corresponding run's resolved_config.yaml when analyzing an ablation.
