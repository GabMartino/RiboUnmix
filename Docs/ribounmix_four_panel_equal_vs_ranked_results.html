01 · Origin

Good reconstruction is not enough to validate the shared signal

RiboUnmix is intended to distinguish a sequence-dependent shared profile from effects that vary between Ribo-seq datasets. A model can fit measured counts well without putting the scientifically relevant structure into the intended branch.

The original five-experiment real-data plan, Experiment 1, therefore asks a different question from prediction accuracy: if we change the entire collection of experiments used for training, do we still obtain a similar shared profile for the same previously held-out sequence?

This is the rationale for four panels. Each model sees a different collection of experimental observations. The test sequences are held fixed. Agreement is informative because it cannot be attributed to training on the same dataset or the same publication family in two panels.

The intended argument is convergence of evidence.

Different experimental collections → separately fitted models → similar positional shared profiles on the same held-out transcripts. That supports a representation that is not specific to one collection of experiments.

It is not, by itself, an identification theorem. The models still share the architecture, sequence inputs and training procedure; broadly shared observation effects or model preferences could also be reproducible. This is why the original plan combines panel convergence with dataset-effect fingerprints, QC associations, biological motif analyses and dataset-diversity experiments. This report covers the panel experiment and its reference-weight sensitivity, not the completion of that wider program.

Conceptual sources: original real-data validation plan; model mathematics. Here, the exported name L_bio is denoted Lt; the variable name is not a biological-truth label.

The stronger hypothesis written in the original plan is that the full model should be more reproducible than its γ = 1 control. The equal-versus-ranked comparison does not replace that control. It asks how the chosen reference measure affects a decomposition that is already present in both arms.

Primary: equal reference

Test convergence without privileging a dataset through the gamma-reference weights. Quality-balanced panel construction and local transcript reliability weighting are still used.

Secondary: quality-ranked reference

Test the sensitivity of the shared representation to an observable-QC-based definition of the reference. A benefit is an empirical hypothesis, not a required outcome.

This ordering is not chosen from the observed scores: uniform π is the primary policy in the original plan, and the ranked run manifest explicitly records “secondary sensitivity analysis.”

03 · Mechanism

π defines the reference for the decomposition, not a second loss weight

The relevant model relationship is a multiplicative decomposition of the expected measured profile:

μdti=SdtLtiγdti S: dataset–transcript scale anchor · L: positive, mean-one shared profile · γ: positive dataset-specific effect.

Let gdti = log γdti. The fixed-reference constraints make the weighted mean of g across the reference datasets zero at each codon, and its positional mean zero within each dataset–transcript profile:

∑d ∈ D(k) πd(k) gdti(k) = 0   and   meani gdti(k) = 0.
Equivalently, the corresponding geometric means of γ are one. In these runs the reference set is the complete selected panel.

Consequently, for the model’s fitted means within a reference panel,

logLti=∑d∈Dπdlog(μdtiSdt). A consequence of the model constraints — not an estimator obtained by geometrically averaging measured counts.

This makes the role of π concrete: it determines which reference-weighted pattern cannot remain as a common effect in the centered gamma branch. Changing π changes the centering operation and the gradients through it during training, and can therefore change what the learned shared branch represents. The ranked outputs here come from separately trained models; we did not change π in a frozen checkpoint after training.

The exact two-way centering operation

For raw log-gamma scores adti, set cti = ∑d πdadti, mdt = meaniadti, and āt = ∑dπdmdt. For reference datasets the centered score is

gdti = adti − cti − mdt + āt,   γdti = exp(gdti).

This is a fixed, checkpointed reference, not the set of datasets accidentally co-occurring in a minibatch. Both arms use the mass-free output: the γL product is not renormalized to conserve the measured count total. The positional gamma constraint is an explicit identification convention in that mass-free model.

See model mathematics, §§5.2–5.4. This report does not infer that the constrained decomposition is uniquely biological.

The two policies used in these runs

Equal:   πd(k) = 1 / |D(k)|.
Ranked:   qd = (R − rd + 1) / R,   πd(k) = qd / ∑e ∈ D(k)qe.
Rank 1 is best; R = 115 is the largest rank in the frozen global table. Power p = 1. All π entries are positive and sum to one within each panel, in both policies.

The 115-entry ranking table and the 114 retained training datasets are different universes: the global ranks are not recomputed within the 28- or 29-dataset panels. Equal weights are therefore 1/29 or 1/28 here, not 1/3. The three-dataset synthetic π example is not this experiment.

The ranked run uses HEK_riboseq_profile_quality_rank.tsv. Its six ranked components are frame periodicity, CDS enrichment, read depth, detected-transcript support, RPF-length center and RPF-length spread. In the saved table, the aggregate score is the sum of these six component ranks. This is an observable-QC ranking, not a ranking derived from ground-truth L or from the test agreement scores.

Do not describe a different ranking in the article. The separate …quality_rank_components.tsv contains ten components, additionally including mapping, contamination and replicate-agreement ranks. That is not the file used for this four-panel ranked run.

The common held-out cohort

The evaluation universe contains 15,929 transcripts with at least two usable selected datasets in every panel. From this universe, the fixed split assigns 1,593 transcripts to validation and 1,593 to test. Both held-out sets are excluded from every panel’s training list. The ranked run reuses these exact memberships and IDs.

Panel-specific training lists include remaining sequence-eligible transcripts meeting the within-panel support rule; their sizes need not be identical. This support-based evaluation favors broadly observed transcripts, so the results should not be extrapolated unchanged to the sparsest transcripts.

What is held fixed

The saved configurations match apart from reference weighting/power and run/path metadata. Both use seed 42, batch size 32, BF16 mixed precision, transcript-grouped sampling, transcript-balanced loss reduction, standard NB, learned dispersion, and mass_conservation=false. Each panel selects its checkpoint by minimum validation loss, not by test PCC or RMSE.

For wdt, dataset depth-scale and score-normalization references are fitted on that panel’s training transcripts and frozen for held-out use. The paired comparison verifies that these reliability-reference contents are unchanged between arms.

Provenance limits that should survive into the Methods or supplement
  • The original training manifests did not record a git commit. Saved configuration agreement does not establish identical historical source code or bitwise training trajectories.
  • The global QC ranking was frozen as an input, but these artifacts do not establish that its component summaries were recomputed using training transcripts only. The verified “train-only” statement applies to local reliability references, not automatically to π. Verify the QC-generation cohort before making a broader leakage-free claim.
  • One panel partition and one training seed do not measure uncertainty across alternative dataset assignments or independent initializations.
  • These are observed-data-balanced panels, not randomly interchangeable biological populations; unrecorded protocol or condition differences can remain.

05 · Measurement

Compare the same positions, transcripts and model pairs

We extract each panel’s frozen shared output from its best-validation-loss test export. Where raw exports repeat a transcript across dataset rows, those shared profiles must agree before a single compact profile is retained. There is no neural fitting in this comparison and no normalization, smoothing or transformation of the exported values.

ρt(a,b) = PCC(Lt(a), Lt(b))
RMSEt=1nt∑i=1nt(Lti(a)−Lti(b))2. Both compare predictions with predictions. There is no measured biological-ground-truth profile on the right-hand side.
  • PCC: agreement in the positional shape of the shared profile; higher means more concordant shape.
  • Inter-panel RMSE: disagreement in the actual profile values, including peak magnitude; lower means closer values.
  • CDS interior: repeat on the same transcripts after excluding exactly 20 codons from each end. Retain the original amplitudes: the interior need not have mean one.
A crucial partial-run rule. Compare equal pair 1–2 with ranked pair 1–2, not the six-pair equal average with the sole available ranked pair. Otherwise the effect of panel identity is mixed with the effect of weighting.

Aggregation and uncertainty

The main equal-weight summary pools the 1,593 × 6 = 9,558 transcript–pair PCC values descriptively. The weighting comparison reports medians across the matched transcript–pair values; its change is ranked median minus equal median, not the median of individual transcript changes.

For the weighting comparison, 5,000 paired bootstrap replicates resample transcripts with replacement. Every selected transcript brings all its matched panel-pair values and both policies together. The reported intervals are percentile 95% intervals, using seed 20260910. They are conditional on these fitted models and this panel partition; the six pairs are not independent experimental replicates.

Positions are aligned without truncating mismatched sequences. A profile variance ≤ 10−12 invalidates PCC; validity/reason codes are saved and finite cohorts are matched between policies. All 1,593 transcripts are valid for both domains and metrics in the current comparison.

Implementation: matched comparison script; bootstrap source table; validity counts.

08 · Interpretation

What we can learn without forcing a preferred outcome

Equal weights already test something scientifically useful

Balancing the panels makes a uniform reference a reasonable primary convention: no dataset is privileged in the gamma center simply because it has a better global rank. The reliability-aware loss still downweights less reliable dataset–transcript observations. Equal-reference convergence therefore does not mean that quality is irrelevant; it means this shared signal is reproducible under a deliberately unprivileged reference measure.

QC can express trust, but is not a direct measurement of systematic bias

A measured QC ranking provides an operational, ground-truth-free way to tilt the reference toward profiles considered more informative. Its strongest interpretation is a documented reference choice. Better periodicity, depth or other QC does not guarantee that a dataset’s positional systematic effects are closer to zero, nor that all highly ranked datasets lack a common distortion. A quality-weighted center can help, do little, or shift the shared profile in a different direction.

Mechanistic possibilities, not findings of this comparison: equal weights may average heterogeneous distortions more evenly; ranked weights may suppress unreliable contributions, but may also concentrate influence on a smaller or more homogeneous set of reference datasets. We have not measured which mechanism explains the observed metric differences.

A higher PCC and a higher RMSE are compatible

PCC captures centered profile shape, whereas RMSE also responds to differences in variation and, for the cropped interior, differences in means. For two aligned profiles, using positional population variances,

RMSE² = σx² + σy² − 2ρσxσy + (x̄ − ȳ)².
The final term vanishes for full mean-one profiles, but their variances and peak amplitudes can still differ.

Illustrative example, not an experimental result: (0.5, 1, 1.5) and (0.25, 1, 1.75) both average to one and have PCC = 1, yet RMSE ≈ 0.204. Agreement in where the profile rises is not agreement in how much it rises. This explains why the metrics can disagree, without proving that an amplitude change is the cause in these fitted models.

The boundary analysis qualifies the apparent PCC benefit

The ranked-minus-equal PCC difference is +0.0130 for the full CDS and +0.0040 for the interior. The latter interval spans zero. The measured full-CDS advantage should therefore not be described as an established improvement throughout the CDS interior. A formal test of the difference between these two changes has not been reported; comparing the two interval outcomes is not itself that test. Boundary-associated structure may be biological, technical, or both.

“The reference matters” is a narrower claim than “ranking is better”

The center has a real mathematical role, and the paired outputs differ. But this partial real-data comparison does not establish that quality ranking uniformly improves reproducibility, and it cannot establish more accurate biological recovery. Ranking can be justified in the article as an independently specified QC-informed sensitivity, with its mixed empirical result reported, rather than as a guaranteed correction.

How much does ranking concentrate the reference?

The descriptive concentration measure 1/∑dπd² equals the panel size under equal weights. Under the saved ranked weights it is 21.15, 21.91, 21.07 and 22.49 for panels 1–4, versus 29, 29, 28 and 28 under equal weights. These values follow from the planned weights, including panels whose training is unfinished.

This is not an estimate of statistically independent sample size and does not predict the neural model’s error. It simply shows that the ranked reference gives a more concentrated distribution of influence. Inspect every dataset’s rank and π.

09 · Supporting evidence, equal-weight run only

Is the agreement just boundaries, large values, or simple codon effects?

Completed post-hoc checks on the four equal-weight models address narrower alternative explanations. They do not change neural parameters or π, and they are not the γ = 1 ablation. No analogous ranked residual comparison is claimed here.

A. Boundary and high-profile-position sensitivity

On a fixed 1,476-transcript cohort valid for the combined boundary/removal conditions, the transcript-level median PCC is 0.7514 on the full CDS, 0.7490 after trimming 20 codons per end, and 0.7174 after additionally removing the union of each panel’s top-1% predicted positions. This supports agreement beyond boundaries, with a contribution from high-profile positions.

In the separately reported full-cohort extreme-removal analysis, the summary changes from 0.7499 to 0.7158 after the top-1% union removal and to 0.6699 after the top-5% union removal. Matched-count random removal gives 0.7502 and 0.7511, respectively. The union of four panels’ selected positions is not necessarily 1% or 5% of the CDS, and the selected positions are predicted high values, not experimentally validated stalls.

Interpretation: high-profile positions contribute disproportionately to agreement, but they do not account for all of it. Their contribution is not evidence that the original agreement is spurious.

Source: completed streaming positional sensitivity; matched combined-condition table.

B. Frozen codon/position diagnostic subtraction

For each panel separately, weighted least squares fits that panel’s own frozen training predictions with a position-only additive baseline, then with codon identity plus position. The fit cohort is the 12,743-transcript intersection of all four training manifests after excluding every validation and test ID. Each transcript receives total fitting weight one.

Position is u = (i − 1)/(nt − 1). The natural cubic spline has boundary knots 0 and 1 and fixed interior knots 0.2, 0.4, 0.6 and 0.8. Codon effects use 63 treatment contrasts with AAA as reference plus an intercept. The two designs have 6 and 69 columns, respectively. Their complexity was not selected to maximize residual agreement.

The frozen panel-specific fitted baseline is subtracted from held-out L. The residuals are signed and are neither rectified nor renormalized; the same fits are used on the interior. These are diagnostic residuals, not alternative biological profiles.

Methods · completed design

To test whether the inferred shared profile depends on the experimental collection used for training, we partitioned 114 Ribo-seq datasets into four disjoint panels of 29, 29, 28 and 28 datasets. The partition kept all conditions and replicates from each of 85 inferred source families in one panel and balanced observable dataset-quality properties. We trained one RiboUnmix model per panel using the same training configuration and seed, with uniform fixed-reference gamma weights within each panel. Local dataset–transcript reliability references were fitted on training transcripts only. All models used the same 1,593 validation and 1,593 test transcript IDs, excluded from every training list. We selected checkpoints by validation loss and compared the frozen, mean-one shared profiles on aligned held-out CDS positions using per-transcript Pearson correlation and inter-panel RMSE.

Results · completed equal-reference study

Models trained on source-disjoint panels produced substantially concordant shared profiles. Across the six panel pairs, median held-out PCC ranged from 0.718 to 0.778; pooling the 9,558 transcript–pair observations descriptively gave a median of 0.752 (interquartile range 0.687–0.797), with median Spearman correlation 0.759 and median inter-panel RMSE 0.437. Thus, the learned positional representation was reproducible across distinct experimental collections, although the non-identical predictions and lower-agreement tail indicate remaining panel sensitivity. These results establish cross-panel concordance, not accuracy against a known biological profile.

Supplementary robustness · optional paragraph

Agreement persisted after accounting for fixed additive codon and broad-position effects. We fitted separate position-only and codon-plus-position diagnostic regressions to each panel’s frozen predictions on the common training-transcript intersection, excluding all validation and test transcripts. On the 1,593 common test transcripts, the median of the within-transcript six-pair median PCC was 0.750 for the original profiles, 0.753 after position-only subtraction and 0.740 after codon-plus-position subtraction; the corresponding interior-CDS values were 0.748, 0.750 and 0.737. These diagnostics support reproducible structure beyond the specified additive baselines, but do not classify removed or residual components as biological or technical and are not a shared-only model ablation.

Quality-ranked sensitivity · provisional, two panels only

We additionally examined sensitivity to a frozen, six-component dataset-QC ranking, retaining the same panel memberships, transcript splits, local reliability references and saved training hyperparameters. For the currently completed matched pair, quality-ranked reference weights increased median full-CDS PCC from 0.7183 to 0.7313 (paired difference 0.0130; 95% transcript-bootstrap CI 0.0084–0.0187), but also increased median inter-panel RMSE from 0.4374 to 0.4646. After excluding 20 codons from each end, the PCC difference was 0.0040 (95% CI −0.0004–0.0098). This partial comparison indicates a metric- and domain-dependent effect of the reference policy, rather than uniform improvement in shared-profile reproducibility. Results from the remaining two ranked panels are pending.
