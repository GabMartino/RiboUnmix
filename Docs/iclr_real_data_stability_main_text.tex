\subsection{Reproducibility and stability across heterogeneous real Ribo-seq datasets}
\label{sec:real_data_stability_main}

We evaluated the model on 114 HEK Ribo-seq datasets aligned to the same MANE
CDS representation.  These data span substantial variation in read depth,
coverage, and experimental quality, while their dataset-specific positional
biases are unknown.  The real-data study therefore cannot measure recovery
against a true biological profile.  Instead, we test whether the inferred
shared component $\mathbf{L}_t$ is reproducible across independent dataset
collections and stable when lower-quality datasets are introduced.  Replicates
remain separate in the count likelihood, and observation reliability is
estimated relative to each dataset's training distribution as described in
Appendix~\ref{sec:real_preprocessing}.

The first experiment tests reproducibility.  We divide the 114 datasets into
four source-disjoint panels of 29, 29, 28, and 28 datasets, keeping all datasets
from the same inferred source family together.  The assignment balances read
density, positive-codon coverage, transcript support, and replicate agreement;
the dataset-quality rank is not used to construct the panels.  Every fit is
evaluated on the same 1,593 held-out transcripts and aligned CDS positions.
Figure~\ref{fig:real_data_stability_main}A reports the six panel-pair
distributions under equal gamma-reference weights.  This comparison asks
whether independently fitted collections contain sufficient common information
to recover the same positional profile.

The second experiment tests stability under controlled dataset addition.  We
form nested collections with $N\in\{2,5,10,20,40,80,114\}$ datasets, ordered
from highest to lowest quality according to the frozen QC ranking, and compare
each inferred profile with one common equal-reference $N=2$ fit.  Equal
reference weights provide the unranked baseline; ranked $p=1$ is the primary
quality-aware reference; reversed $p=3$ is a deliberately strong
adverse-reference control.  These weights set
the identifiability reference for the dataset-specific correction and do not
discard or downweight observations in the likelihood.  Because the rank weights
remain close to uniform through $N=20$, the larger collections provide the more
informative ranking intervention.

The balanced panels recover strongly concordant shared profiles
(Figure~\ref{fig:real_data_stability_main}A), supporting a reproducible signal
that is not tied to one publication family or dataset subset.  This agreement
does not establish that $\mathbf{L}_t$ is the unknown true biological
profile, because the common architecture and regularization also promote
similar solutions.

In the exploratory cumulative run, the equal-reference profile progressively
moves away from the $N=2$ solution, while the advantage of ranked $p=1$ is
small and non-monotonic (Figure~\ref{fig:real_data_stability_main}B).  The
strong reversed $p=3$ control produces greater displacement at larger available
sizes, showing that an adverse, concentrated gamma reference can materially
alter the decomposition.  It does not by itself prove that the QC ordering
stabilizes $\mathbf{L}_t$, since it is more concentrated than ranked
$p=1$.  Moreover, this partial run shares the test cohort across $N$ but not the
training and validation cohorts.  The ranking claim therefore remains
provisional until the fixed-cohort experiment is complete at the informative
$N=80$ and $N=114$ endpoints.
